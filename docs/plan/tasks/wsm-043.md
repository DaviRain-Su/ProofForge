# wsm-043 XrplMint total supply（`supp`）

`supp` JSON key lives on the minter card, same pattern as `halt`. Not a
`State` field (persist would copy it onto dest cards). Not Sdk.Map.

`Examples.XrplMint` digest `f3badc5d09e3c5bc`. Runtime leaves
`flushSupp` / `peekSupp` (`xflushs` / `xpeeks`); key `supp` at offset 88.
mint / mintTo increment, burn decrement, pay unchanged.

活网：A `mint(5)` 后 `pay(B,2)` → A.bal=3 B.bal=2 A.supp=5；A `mintTo(B,4)`
→ B.bal=7 A.supp=9；`mintTo(B,u64Max)` 状态码 1，卡不变；A `burn(1)` →
A.bal=1 A.supp=8。
