# wsm-041 内部积分转账（XrplPay）

一次 `ContractCall` 写两张 caller 卡：先 `flushBal` 把 caller 减额落到当前
Owner，再 `peekOwnerLimbs` 切到对方 20B、读对方 `bal`（缺卡当 0），最后 persist
把加额写到对方卡。不是 XRP Payment，不是 Sdk.Map。

`Examples.XrplPay` digest `fc70ebc09ea82a40`。活网：A `credit(5)` 再
`pay(B,2)` → A=3 B=2。

## 不做什么

- 不开 `Sdk.Payments` / `emit_built_txn`
- 不把 bump allocator 当 SDK 底座
- 不进 CI
