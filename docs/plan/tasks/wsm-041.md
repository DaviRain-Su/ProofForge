# wsm-041 内部积分转账（XrplPay）

一次 `ContractCall` 写两张 caller 卡。先 `peekOwnerLimbs` 确认 dest 不会溢出，
再 `storeOwnerLimbs` 切回 caller、`flushBal` 减额，最后再 peek dest 加额。
余额不足或 dest 溢出会在 `flushBal` 之前失败，caller 卡不变。不是 XRP Payment，
不是 Sdk.Map。

`Examples.XrplPay` digest `5f2a9ac1b78e08de`。活网：A `credit(5)` 再
`pay(B,2)` → A=3 B=2；`pay(B,9)` → 状态码 1，A/B 仍 3/2；B `pay(A,1)` → A=4 B=1；
A `pay(A,1)` 自转账 alias-safe，A/B 仍 4/1；B 加到 `u64Max` 后 A `pay(B,1)`
→ 状态码 1，A 仍 4；A `pay(B,0)` 零额成功，A/B 仍 4/`u64Max`。

## 不做什么

- 不开 `Sdk.Payments` / `emit_built_txn`
- 不把 bump allocator 当 SDK 底座
- 不进 CI
