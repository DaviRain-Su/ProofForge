# wsm-056 spender `burnFrom` 源卡

## objective

Compile-time spender burns `amount` from a parameter AccountID card.
Cuts that card's `allw`, decrements minter `supp`, then restores caller
before persist so `$bal` is not copied onto the spender card.

digest `aa7a5ca7cb887256`.

- 非 spender → 3
- 源 `lock≠0` → 5
- 缺 allw / 余额 / supp → 1
- 成功：源 `bal` 减、`allw` 减、`supp` 减；spender `bal` 不变
