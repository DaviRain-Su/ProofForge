# R4-011 — Add full-width address balance observation

## Goal

Expose Solidity-shaped `address.balance` without truncating the address or Wei value and without
adding another top-level operation, IR node, or main-emitter recipe.

## Delivered contract

- `Evm.Sdk.Address.balance (address : Address) : UInt256` binds the EVM `BALANCE` observation.
- All three source Address limbs pass through `Component.environment`; the target interpreter uses
  the existing fixed 32-byte address packing helper before applying `BALANCE`.
- The target captures one EVM word per query and projects all four numeric UInt256 limbs from the
  shared cache. Unlike `Address.codeHash`, the result uses numeric word projection rather than the
  source-order fixed-bytes conversion.
- The query is read-only and allocation-free: it performs no storage write, memory allocation,
  external call, or log operation. Raw account/code bytes remain outside the safe SDK.

## Evidence

- `Tests.EvmEnvironmentSpec` pins three-operand arity, limb bounds, Component ownership, and one
  `BALANCE` occurrence for the four-limb return.
- Anvil compares a funded address against `cast balance` (a value larger than UInt64) and verifies
  a nonexistent address returns zero.
