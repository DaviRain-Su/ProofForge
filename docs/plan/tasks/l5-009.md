# l5-009 Phoenix-v1 account-resident body metadata

## objective

在不开放 Rust heap、SVM `Map`、runtime offset 或动态节点数组的前提下，读取官方
Phoenix-v1 `FIFOMarket` 的固定 scalar 和三棵 Sokoban tree allocator `size`。12 个官方
profile 只在编译期选择四组固定账户 offset。

## layout

- `MarketHeader`：576 B；`FIFOMarket` 前 256 B 是 padding
- `order_sequence_number`：absolute u64 word 106
- bids allocator `size`：absolute u64 word 112
- asks allocator `size`：book capacity 512/1024/2048/4096 分别位于 word
  4212/8308/16500/32884
- traders allocator `size`：对应位于 word 8312/16504/32888/65656
- count 必须分别不超过 bid/ask compiled capacity 和 header seat capacity

这里的 Sokoban allocator 是账户内 `bump_index + free_list_head + [Node; N]` 槽管理，
不是 Rust global allocator，也不是 `HashMap` / `BTreeMap`。

## path

`Projects/PhoenixV1Profile.lean`, `Tests/PhoenixV1ProfileSpec.lean`,
`runtime-tests/solana/tests/phoenix_v1_profile.rs`

## verification

- Lean guard 钉住所有四档 allocator size word 和 capacity gate
- 12 个官方 profile 在 Mollusk 返回 sequence 777 和 body entry count 6
- bids/asks/traders 任一 count 超过其 capacity 都返回 0
- profile owner/discriminant/length gate 仍先于 body read

## non-goals

- 不分配、复制或摊平 512..8321 个节点
- 不开放 runtime-selected account-data offset、Rust iterator `Vec` / `Box` 或 SVM Map
- 不沿 root/left/right 做动态节点遍历，不写 allocator/node，不开放 remaining accounts
- 不宣称完整 Phoenix-v1 body compatibility
