# l4-031 32B key / owner 按字读

## objective

完整 32B pubkey 仍不能当一个 `UInt64` 返回。开通用按字叶子，不堆 `accKey0w0`…`accOwner1w3` 十六个特化。

- Lean：`accKeyWord (acc word : UInt64) : UInt64`、`accOwnerWord (acc word : UInt64) : UInt64`
- `acc` ∈ {0,1}，`word` ∈ {0,1,2,3}，抽出时必须是常量；其它 fail closed
- 返回该 32B 的第 `word` 个小端 u64
- `accKeyWord 0 0` **不**等于 `signerKey0`：不强制入口 `is_signer`
- `acc ≥ 1` 触发 walk，不强制 acc0 signer
- 新例子 Keys，不改 Info / Peer / Clock
- 现有 `signerKey0` / `accOwner0` / `accOwner1` / Hash digest 不回退

不是 CPI。不是 `ByteArray 32`。账户 2+ 仍 FC。

## path

`Ops.lean`, `Runtime.lean`, `Extract.lean`, `IR.lean`, `Emit.lean`,
`Golden.lean`, `Examples/Svm/Keys.lean`, `Tests/*`, `runtime-tests/solana/tests/keys.rs`

## verification

- Keys Mollusk：账户 0/1 的 key 四字、owner 四字与宿主 `Pubkey` 字节一致
- `acc=1` 只给 1 个账户 → Custom(1)
- `signerKey0` 缺 signer 仍 Custom(1)；Keys 的 word 叶子不强制 signer
- Peer digest 仍是 `db69bdf1efa1011d`；Hash digest 仍是 `2fb59b956afdf97f`

## result

- Keys digest `b91c2a143e8ff667`；walk、非 CPI
- Mollusk：账户 0/1 的 key / owner 按字与宿主 `Pubkey` 一致；`key00` 不强制 signer；缺第二账户 Custom(1)
- Peer / Hash / Clock digest 不回退
