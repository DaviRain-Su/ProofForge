# wsm-015 AlphaNet 零参数 Ownable（XrplGate + pf deploy/call）

## objective

公开 AlphaNet 仍 502 带 `Parameters` 的 `ContractCall`。`XrplOwn` 的 `init`
有一个哑参数，活网调不了。本刀加 `Examples.Xrpl.XrplGate`：

- 零参数 `initialize` 把 `Context.caller` 三叶写成 owner
- 零参数 `bump` 走已有 `Access.requireOwner`
- 零参数 `renounce` 把 owner 三叶清零
- 同一把创世钥匙再 `bump` → wasm 状态码 **3**，`value` 不变

不新 host、不新 Op。`pf deploy` / `pf call` 默认 `--target xrpl-alphanet`，
包 `runtime-tests/xrpl/alphanet-rpc.js`。活网门是 `gate.sh`，不进 CI。

## 不做什么

- 不改 `XrplOwn` digest（Bedrock 本地第二账户门仍用它）
- 不把 live AlphaNet 放进 CI
- 不做两步移交、不接 Payment、不加第二把 AlphaNet 钱包
