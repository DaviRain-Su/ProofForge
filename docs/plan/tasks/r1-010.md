# R1-010 — EVM Bounded Array v1 input

## Goal

Bind the shared `Core.Value.BoundedVec α capacity` source carrier to canonical standard-ABI
dynamic array input without copying SVM Borsh geometry or materializing an unbounded target
collection. The source capacity remains compile-time metadata; EVM execution receives a fixed
scalar frame.

This slice covers **function inputs only**. Bounded dynamic constructor inputs, dynamic returns,
nested dynamic elements, unbounded `Array`/bytes, and frames larger than 64 scalar words fail
closed.

## Target contract

`ProofForge EVM Bounded Array v1` uses standard ABI `T[]` for a statically shaped element `T`:

- the top-level head contains one offset word;
- offsets are relative to the argument block after the selector and must point to the exact next
  canonical tail (no gaps, aliases, or reordering);
- each tail contains `length:uint256 || length × flattened-static-element` ABI words;
- `length ≤ capacity`, every active scalar word passes the existing bool/uint/address/bytesN
  canonical padding guard, and the final tail must consume calldata exactly;
- the target-local frame is `length:uint32 || capacity × flattened-static-element`; inactive
  element locals are initialized to zero before the contract CFG runs.

The host `Vector` backing `BoundedVec` is erased during extraction. The generated contract has no
array header, backing pointer, allocator call, persistent Map/Array, or runtime-selected geometry.

## Ownership and abstraction

- `Evm.Codec.BoundedArrayPlan` owns capacity and static element-word geometry.
- `Evm.Codec.inputPlan` owns source projections, Solidity type spelling, the fixed local frame,
  and a policy identity that includes capacity even though the selector only contains `T[]`.
- `Evm.IR` performs the existing generic logical-to-physical projection rewrite. There is no array
  Ops/IR node.
- `Evm.Codec.Emit` is the reusable input-plan interpreter for static, Tagged Tuple v1, and bounded
  dynamic inputs. Main `Evm.Emit` only asks that component to render the entry boundary; no
  contract/application policy or array operation was added to the CFG emitter.
- ABI JSON exposes standard `T[]`. Dynamic constructors are rejected by both Yul and ABI artifact
  emission so the two artifacts cannot disagree.

`Examples.EvmBounded` is an application fixture, not Runtime policy. It covers one bounded array
and a mixed static/two-dynamic-array signature.

## Fail-closed matrix

The dedicated Lean/Anvil gates reject:

- wrong/noncanonical first and later dynamic offsets;
- `length > capacity`;
- short tails and trailing words;
- noncanonical high bits/padding in active narrow elements;
- nested dynamic element schemas;
- a fixed local frame larger than 64 words;
- bounded dynamic constructor input.

Empty, partially active, full-capacity, and multiple contiguous tails succeed. Partial inputs prove
that inactive source slots are zero rather than out-of-bounds calldata reads.
