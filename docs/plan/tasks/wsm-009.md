# wsm-009 XRPL-SDK-EQ：可组合的三叶 `AccountId.eq`

## objective

wsm-006 证明了三叶比较能上链；wsm-008 只挂了 `Context.*` 名。本刀把比较收成
SDK helper，Ownable 不再手写三层 `if`。

`AccountId.eq` 是 `@[pf_inline]`，展开成嵌套 `if` 三叶 `UInt64` 相等。不用 `&&`
（wasm v0 拒 `bitAnd`）。不是新 host，不是 EVM `eq20`。

`Examples.Xrpl.XrplOwn.bump` 改走 `AccountId.eq Context.caller …`。WAT 仍含三个
`i64.eq` 和状态码 3。digest 可以变（IR 形状从手写 ite 树变成 helper 展开）。

## 不做什么

- 不引入 `eq_account` host
- 不做 Map / event / 动态 hash
- 不把 `callerLo` 当权限目标

## path

`ProofForge/Wasm/Xrpl/Sdk.lean`，`Examples/Xrpl/XrplOwn.lean`，`Tests/XrplSpec.lean`，
`docs/plan/analysis/xrpl-runtime.md`

## verification

- `#pf_xrpl_build Examples.Xrpl.XrplOwn`；WAT 仍有 ≥3 个 `i64.eq` 和 `(i32.const 3)`
- 本地 `own.sh`：owner bump 改 value；非 owner 返回 3
