# l4-030 sol_sha256 / sha256Lit

## objective

`sha256Lit` 是运行时叶子，不是 CPI recipe。

- Lean：`sha256Lit (seed : String) : UInt64` — 编译期 ASCII 字面量；返回 32B digest 的第一个小端 u64
- 抽出按名字认；发射 `sol_sha256`，一条 `SolBytes`，`r2 = 1`
- 完整 32B / 多切片 / 运行时缓冲 / keccak / blake3 仍 FC
- 新例子 Hash，不折进 Info / Peer
- 现有叶子、Peer digest 不回退

官方 C ABI：

```
void sol_sha256(const SolBytes *bytes, int bytes_len, uint8_t *result);
typedef struct { const uint8_t *addr; uint64_t len; } SolBytes;
```
