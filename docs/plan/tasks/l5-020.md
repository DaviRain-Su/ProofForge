# l5-020 exact second Phoenix trader registration

## objective

按 Sokoban 0.3.0 的账户内 bump allocator 和 red-black tree transition，把最小 128-seat
trader tree 从 canonical 单黑根推进到两个节点。新节点必须按 Rust `[u8;32]` 原始字节序
挂到 root 左或右侧；不分配 heap container，不复制树，也不保存 pointer。

## invariants

- 输入必须是 84,944-byte `(512,512,128)` shape，trader header 必须是
  `root=1, padding=0, size=1, bump=2, free=2`；root links 和 parent/color 均为零
- 四个 little-endian u64 limb 各自 byte-swap 后逐 limb unsigned 比较，等价于 Solana
  `Pubkey([u8;32])` 的 lexicographic `Ord`，不能按 limb 数值或 base58 文本排序
- 第二次 bump allocation 原子发布 `size=2, bump=3, free=3`；slot 2 全部 18 words 被覆盖，
  links 为零、`parent=1,color=Red(1)`、key 为输入、TraderState/reserved 为零
- root 保持黑色和 address 1，只把 address 2 写入 left 或 right register；第二个节点的
  parent 是黑根，因此按官方 `_insert` 不需要 recolor/rotation
- 成功路径精确保留 21 个 account-resident writes；existing root key/TraderState 不被改写，
  complete trader validator 必须在左右两种结果上返回 1
- duplicate 或 malformed one-root state 以 `Custom(0x1001)` fail closed；readonly/wrong-owner
  store 以 `Custom(1)` 失败；所有失败保持完整账户 bytes 不变

## path

`Projects/PhoenixV1Profile.lean`, `Tests/PhoenixV1ProfileSpec.lean`,
`runtime-tests/solana/tests/phoenix_v1_profile.rs`

## verification

- Lean guards 钉住 byte swap、跨 limb raw-byte ordering、canonical header reads、18 个 node
  writes、cursor/size/root-link writes 和总计 21 个 effects
- Mollusk 用刻意与 little-endian limb 数值序相反的 key，分别得到 slot 2 left/right child；
  stale slot 全覆盖、existing TraderState 保留、`bodyEntryCount=2`、`traderTreeValid=1`
- duplicate、malformed root、readonly、wrong owner 均原子失败；profile suite 14/14
- digest `f741f2eaffde779e`；assembly 3,888,574 B；ELF 1,248,584 B；IDL 4,058 B
- Surfpool 1.5.0 用 1,234 个 Loader write + deploy + authority transactions 完成本地部署，
  并核对 exact 1,248,629-byte ProgramData；不用 `solana-test-validator`
- 全量 194-job Lean、50 个 SVM build、Mollusk 212/212 与 Anvil 12/12 回归通过

## non-goals

- 不实现第三个/一般 key 插入、duplicate idempotent lookup、free-list reuse 或 rotation/delete
- 不开放 runtime account shape、remaining accounts、动态容量或完整 Phoenix-v1 instruction ABI
- 不声明公网部署，也不把 transient bump heap 当 persistent allocator
