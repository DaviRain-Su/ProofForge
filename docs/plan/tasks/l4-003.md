# l4-003 编译期钉死的 invoke 原语

## objective

把 transfer 的 walk + `sol_invoke_signed_c` 收成通用 op，不再为每个 callee 复制发射器。

- `Ops.Op.invoke`：编译期 `programIx`、`metas`（下标 + signer/writable）、`data`（字面量字节 + `Val` 叶）。
- `systemTransfer amount` 抽出成这条 op 的特化：program=2、metas=`[(0,s+w),(1,w)]`、data=`u32le(2)||u64le(amount)`。
- 第二条 callee：`invokeAcc1` 调外层账户 1 上的固定 stub ELF，空 metas/data。证明 program id 来自该账户 key，不是写死 System。
- N 账户 walk（先 2..4）。运行时 program id / remaining accounts / 变长 data 仍 FC。
- `invokeSigned` / PDA seeds 本切片不做。
