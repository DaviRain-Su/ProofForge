# evm-002 Ops → Yul（constructor / entry / view / overflow）

## objective

薄发射器。只覆盖当前 Ops 的 UInt64 子集。形状对齐 PF Counter，不搬 `EmitIRV1`。

- constructor：`callvalue` 守卫、精确 ctor ABI、`uint64` 高位清零、按 `returnState` 写 slot、拷 runtime
- entry：`switch shr(224, calldataload(0))`、精确 calldata、checked 四则在运算前 revert、`okState` 写 dest slot 并 `return` 32 字节
- view：`sload` + return，不写
- overflow / 未知 selector / 短 calldata → `revert(0, 0)`

无 SVM 叶子。无 Map / `msg.value` / CALL。
