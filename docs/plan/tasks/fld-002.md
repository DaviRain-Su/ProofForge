# fld-002 从 structure 收字段表 + Pair .so

## objective

`#solana_extract init mut get` 从 `init` 返回类型的 `structure` 按声明顺序收 `Program.fields`。不再依赖 `with "left","right"`。只接受全 `UInt64`、无 `extends` 的 structure。未知字段 / 非 UInt64 fail closed。

布局 marker 按字段表走 PF 公式。单字段 `value` 仍映射为 StateCell 的 `count`（Counter Mollusk 不回退）。Pair 汇编成 `Pair.so`，Mollusk：`data_len=24`、right 在 +16、creditLeft 只改 left。

## path

`SolanaLean/IR.lean`, `Extract.lean`, `Commands.lean`, `Emit.lean`, `Assemble.lean`, `AssembleMain.lean`, `Tests/*`, `runtime-tests/solana/tests/pair.rs`

## verification

- Pair 无 `with` 抽出，fields = left, right
- 含 `Bool` 字段的 structure 拒绝（`Nat` 仍先被 Profile 挡）
- Counter Mollusk 4/4
- Pair Mollusk：init / creditLeft 保 right / getLeft / overflow 保持
