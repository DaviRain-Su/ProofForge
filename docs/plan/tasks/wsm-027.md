# wsm-027 每用户一张卡（XrplBal）

## objective

XLS-0101 的 user ContractData 是 **多用户**：每人一块，Owner=账户。
不是单用户金库。AlphaNet 每次调用写 **caller** 那块（写合约账户 -22）。

`Examples.XrplBal`：零参数 `credit` 给 **本次 caller** 的 `"bal"` +1。
活网：钱包 A credit 两次 → A=2；给 B 打款后 B credit 一次 → B=1 且 A 仍 2。

digest `cfae015ada92cdc9`。不新 host。

## 不做什么

- 不在一次调用里给别人写卡（`setUserData(destination)` 仍未证）
- 不叫 `Sdk.Map` / 不搬 wee_alloc
- 不进 CI

## verification

- `#pf_xrpl_build Examples.XrplBal`
- `runtime-tests/xrpl/bal.sh`：A=2、B=1（B 未打款则 skip 后半，不把 skip 当绿）
