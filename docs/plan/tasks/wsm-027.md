# wsm-027 每用户一张卡（XrplBal）

## objective

XLS-0101 的 user ContractData 是 **多用户**：每人一块，Owner=账户。
不是单用户金库。AlphaNet 每次调用写 **caller** 那块（写合约账户 -22）。

`Examples.Xrpl.XrplBal`：`credit(delta)` 经 `function_param` 给 **本次 caller** 的 `"bal"` 加 UINT64。
活网：钱包 A `credit(3)` → A=3；给 B 打款后 B `credit(5)` → B=5 且 A 仍 3。

digest `3177150879f2b85a`。不新 host。

## 不做什么

- 不在一次调用里给别人写卡（`setUserData(destination)` 仍未证）
- 不叫 `Sdk.Map` / 不搬 wee_alloc
- 不进 CI

## verification

- `#pf_xrpl_build Examples.Xrpl.XrplBal`
- `runtime-tests/xrpl/bal.sh`：A=3、B=5（B 未打款则 skip 后半，不把 skip 当绿）
