# sf-013 BatchRecorder begin/append/finish

## 目标

用 TransientModel（Bytes）叙述 recorder：满员先 flush 语义在模型层可陈述的部分；empty finish header-only。

## 交付

1. begin 后可 append；超 record 界触发 finish 条件（按 SDK 定义）
2. empty finish 仍产生固定 header 长度的叙述（常量级）
3. 不把堆指针写入账户模型

## 进度

已落地（纯 L2 Bytes 叙述，`ProofForge/Svm/Sdk/BatchRecorderModel.lean`）：

* `Geometry` / `Recorder` / `Batch`：只保留配置几何、active、length/count 与逻辑字节
* `mBegin` / `mAppend` / `mFinish`：同 SDK 的 active-first、disabled no-op、full→flush、finish invalidate 控制流
* begin→append 直达成功；`maxRecords` / `maxBytes` 满批先 flush；fresh batch 也装不下则 `finishNeeded` 且不变
* inactive / stale geometry 的 append/finish 均 fail-closed 且不变
* empty finish 的 emitted length 精确为 `headerBytes`
* `Recorder.no_account_words_or_heap_pointers` 给出纯逻辑字段完备投影

待补：BytesWords/Emit 的逐指令 correspondence 属于后续 L3 语义桥，不阻塞本片纯 L2 验收。
