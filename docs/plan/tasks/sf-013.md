# sf-013 BatchRecorder begin/append/finish

## 目标

用 TransientModel（Bytes）叙述 recorder：满员先 flush 语义在模型层可陈述的部分；empty finish header-only。

## 交付

1. begin 后可 append；超 record 界触发 finish 条件（按 SDK 定义）
2. empty finish 仍产生固定 header 长度的叙述（常量级）
3. 不把堆指针写入账户模型
