# R0-001 — Freeze Runtime / SDK ownership boundaries

## Goal

Freeze the dual-target ownership model before adding more language surface. Record which layer owns
each source capability, component bridge, target effect, and physical state model; add a CI gate so
future application work cannot leak protocol policy back into target Runtime or Emit modules.

## Delivered

- `capability-matrix.md` now maps the shared language, SVM, EVM, and application surfaces through
  owner, component/lowering boundary, target effect, physical state, and fail-closed edge.
- The matrix makes the storage split explicit: SVM owns fixed account bytes, stride/capacity,
  one-based indexes, and bounded invocation scratch; EVM owns static slots and typed hashed
  namespaces. The targets share semantic values and control, not a fictitious common storage API.
- `scripts/check_ownership.py` rejects direct `Examples` imports of SVM/EVM Emit modules, target
  imports of `Examples` or `Projects`, and application protocol vocabulary in production target
  modules. Registries remain the deliberate artifact-enumeration exception. CI runs this gate before
  the Lean build.
- Generic SVM Runtime, account-storage, FIFO-cancellation, and emitter descriptions now use generic
  key4/two-word ordered-map vocabulary. Phoenix protocol names, layout, matching, fee, and wire
  policy remain under `Examples`.
- No Ops, IR, CFG, Component, Runtime behavior, storage geometry, or emitter recipe changed. Queue,
  Map, RBMap, allocator, recorder, and codec work must first compose source/SDK descriptors; a new
  target effect remains the only reason to extend the low-level instruction vocabulary.

The frozen ownership path is:

```text
Examples protocol policy + concrete layout
        │ typed target SDK / Source facade
        ▼
generic static descriptor + dynamic scalar operands
        │ Component bridge
        ▼
target Runtime / Emit effect
        │
        ├── SVM: fixed account bytes or bounded invocation scratch
        └── EVM: static/hashed storage slots or bounded call memory
```

- The full SVM manifest built all 51 programs and the locked Mollusk suite passed 285/285. The full
  EVM manifest built all 15 programs and Anvil passed 15/15.
