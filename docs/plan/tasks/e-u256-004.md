# E-U256-004 — checked UInt256 division and modulo

## Goal

Complete reusable unsigned 256-bit arithmetic without exposing raw EVM zero-divisor behavior or
teaching the main emitter two source-specific recipes.

## Delivered contract

- `Evm.WideWord.Division` names quotient and remainder without numeric operation tags.
- `WideWord.Query.checkedDivMod256` carries exactly two four-limb words and one result-limb
  projection through the existing component bridge.
- The target interpreter reuses the same bounded pack/cache/project path as binary bitwise
  operations. It emits one packed Yul `div` or `mod`, caches the word result, and projects four
  fixed limbs.
- `Evm.Sdk.UInt256.div` and `mod` provide the source-facing API. `Examples.Evm.Wide` is only the
  contract fixture; contracts do not manipulate limbs or Yul operations themselves.

Both operations are checked: a zero divisor reverts before the Yul operation. Raw EVM
`div(x, 0) = 0` and `mod(x, 0) = 0` therefore do not leak into SDK semantics.

## Resource and failure boundary

- Each query requires exactly eight operands and a result limb in 0..3; malformed shape fails
  closed before emission.
- The operation has no runtime allocation, memory buffer, storage handle, CALL, LOG, or hidden
  state effect. Its only intermediates are three bounded Yul stack words.
- The emitter test pins the zero-divisor guard for both operations; Anvil tests both successful
  cross-limb arithmetic and zero-divisor reverts.
