# R1-034 — Shared bounded byte and string substring search

Date: 2026-09-01
Status: done

## Goal

Give both targets one reusable allocation-free substring policy for bounded bytes and strings,
comparable to Rust slice/String `contains` and Solidity bytes/string search helpers, without adding
a search opcode, target component, allocator, pointer, or emitter recipe.

## Delivered contract

- `BoundedBytes.contains` accepts independently sized haystack and needle carriers. It rejects
  either over-capacity frame, treats an empty canonical needle as present, rejects a nonempty needle
  longer than the haystack, and ignores both inactive tails.
- The implementation flattens the finite candidate/needle product into one compile-time-bounded
  scalar scan. A private two-bit lowering state tracks the current candidate and any completed
  match; no representation tag is exposed by the Bool API.
- `BoundedString.contains` delegates through the compiler-erased byte view. String validity remains
  a checked-constructor/target-codec invariant; search is exact UTF-8 byte-substring policy, not
  Unicode-scalar matching, normalization, collation, or pattern syntax.
- Extract now evaluates closed Nat arithmetic when recovering a source loop range, so a bound such
  as `capacity * needleCapacity` is retained as the exact static product. Structural tests pin 64
  iterations for the SVM capacity-8 consumer and 9 for the EVM capacity-3 consumer.
- SVM `RawEntry` tags 31/32 bind canonical dual Borsh frames. `Examples.Evm.EvmSearch` is deliberately
  an application/example consumer rather than an SDK duplicate: it binds dual adjacent standard-
  ABI tails independently, while Core remains the sole policy owner.

## Evidence

  independently sized carriers, String delegation, and UTF-8 byte sequences.

  Bool exits, dual Borsh plans, dual ABI tails, and both String UTF-8 gates.
- RawEntry Mollusk covers empty, longer, present, absent, overlapping, UTF-8, and malformed UTF-8

## Boundary

This is exact bounded substring policy, not prefix/suffix convenience APIs, split/replace,
concatenation, regex/pattern search, Unicode normalization/collation, allocation, persistence, or a
shared wire layout. The only compiler change is generic closed static-range evaluation; no Runtime,
Ops, IR, CFG, Component, or Emit operation/case was added.
