# R3-029 — Typed transient wide vectors

Date: 2026-08-31
Status: done

## Goal

Provide allocation-free invocation-local `UInt128` and `UInt256` vectors without adding a second
heap, exposing raw words to applications, or teaching Runtime/IR/Emit a container-specific recipe.
Every mutating operation must preserve whole-value alignment and reuse the existing bounded
`Vector64` lifecycle and its two compile-time slots.

## Delivered contract

- `Svm.Sdk.Transient.Vector128` and `Vector256` derive fixed two-/four-word records from the
  existing `Record64` facade. Their descriptors carry only element capacity and slot selection;
  extraction erases them to existing transient-vector effects.
- Both provide `begin`, `length`, `isFull`, typed whole-value `push/get/set/last`, `dropLast`,
  `truncate`, `clear`, and `finish`. Push preflights room for the complete record before its first
  word write; set validates the record index before its first mutation.
- Full/OOB, stale/mismatched handle, and shared-heap OOM retain the existing `0x1202`, `0x1203`,
  and `0x1201` outcomes. Drop/truncate operate in logical elements and cannot leave a partial wide
  value.
- `TransientWide128` chooses reject-at-full policy. `TransientWide256` independently chooses
  clear-and-reuse-at-full policy. Application behavior remains under `Examples`.
- The shared static-wide-result fix from R1-023 serializes all two/four limbs after component
  effects; runtime checks require exact 16-/32-byte little-endian result frames.

## Evidence

- Focused Lean extraction and geometry guards pass. They reject every target extension except the
  existing transient-vector component, prove complete two-/four-word push branches, retain both
  slots and inherited failure gates, and pin 16-/32-byte return-data emission.
- TransientWide128 digest is `be610f5f69db20a6`; assembly is 771,373 bytes and ELF is 220,032
  bytes with SHA-256 `f78884da8add55d2a3fef2b9731a12791277a8f292e0ffdfe88ba20919592cb6`.
- TransientWide256 digest is `a0985f87fb42010c`; assembly is 800,517 bytes and ELF is 228,712
  bytes with SHA-256 `01d1836bbfebbd1cb582c8ae86bb9f0fdbabaf8e7af2078c868eb008eca0007b`.
- Focused locked Mollusk passes 8/8, covering exact/full boundaries, no-partial-push rejection,
  runtime set/get, logical drop/truncate/clear, stale handles, two-slot isolation, shared-heap OOM,
  and complete typed return frames.

## Boundary

This slice supports only `UInt128`/`UInt256` invocation-local values over the existing two
`Vector64` slots. Generic polymorphic elements, more slots, insert/remove-at, iterators, reclaim,
reallocation, persistent pointers, and account-persistent storage are separate capabilities. No
Runtime leaf, Ops/IR/Component/Emit case, allocator, map, or application-specific lowering was
added.
