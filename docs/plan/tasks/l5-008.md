# l5-008 Phoenix-v1 canonical market profile gate

## objective

在解释动态 market body 前，先按 Phoenix v1 官方 dispatch 边界验证账户 1：canonical
program owner、`MarketHeader` discriminant、24-byte `MarketSizeParams` 白名单和 exact
account length。runtime tuple 只选择预编译 profile，不创建任意长度数组。

## profile

- Header：576 bytes；discriminant `8167313896524341111`
- Body：`400 + 64 * (bids + asks) + 144 * seats`
- 完整账户：`976 + 64 * (bids + asks) + 144 * seats`
- 容量：bids/asks ∈ {512, 1024, 2048, 4096} 且相等；每档 seats 只接受官方三值
- 最小 profile `(512, 512, 128)`：body 84,368 B，完整账户 84,944 B

## verification

- 12 个官方 tuple 的 exact full-account bytes
- owner / discriminant / tuple / data length 任一错误都不选择 profile
- `accDataWord acc word` 仅接受编译期常量账户/word，读前检查 `data_len`
- 12 个官方 profile 在 Mollusk 逐一返回 exact full-account bytes；32-byte 短 header
  读 word 4 以 `Custom(1)` fail closed

## non-goals

- 不把 512/1024/2048/4096 个节点摊平成现有 state slots
- 不解释或写入 Sokoban body
- 不开放 runtime account index、动态 CPI metas、remaining accounts 或变长 instruction data
- 不宣称完整 Phoenix-v1 program/account compatibility
