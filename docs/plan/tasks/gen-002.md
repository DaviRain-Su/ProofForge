# gen-002 按 Op 发射 handler 体

## objective

`emitCounterAsm` 的 handler 体由 `Method.ops` 生成。有 `checkedAddU64` 才吐 `0x1001`；有 `returnU64`/`okState` 才吐 `sol_set_return_data`。空 ops 的形状 IR 不得发射 overflow。Loader 预检外壳仍共享。

## context

docs/01-prd.md（证明在本机，链上只跑抽出的计算）；docs/modules/ops.md

## path

ProofForge/Emit.lean, Tests/EmitSpec.lean, docs/modules/emit.md

## verification

抽出后的 Counter 仍含 overflow / return data；`IR.counterProgram`（空 ops）发射失败或正文不含 `0x1001`。
