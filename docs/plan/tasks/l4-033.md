# l4-033 账户下标叶子收口

## objective

把账户 header / signer / owner 比较收成编译期下标，不再堆 `acc*2` 特化。

- Lean：`accLamports` / `accDataLen` / `isSigner` / `isWritable` / `isExecutable` / `signerKey` / `ownerIsSelf`，参数 `acc`∈{0,1,2}
- `accKeyWord` / `accOwnerWord` 的 `acc` 上限从 1 扩到 2
- `acc ≥ 1` 走 walk；walk 下界 = `max(acc)+1`
- `signerKey acc` 强制该账户 `is_signer`（含 walk prelude）
- `ownerIsSelf acc`：owner 32B 与当前 program id 比，相等 0 / 不等 1
- 旧 `accLamports0` / `signerKey0` 等不改名、不改抽出，digest 不回退
- 新例子 Trio

- `ownerIsSelf 0` = 0；`ownerIsSelf 2` 在异 owner 时 = 1
- Peer / Keys / Clock digest 不回退
