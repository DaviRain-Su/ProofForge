# l5-026 fixed-capacity Phoenix bid/ask insertion

## objective

为最小官方 Phoenix-v1 profile 的 512-node bid/ask books 增加通用 fixed-capacity
account-resident insertion effect。按 Phoenix `FIFOOrderId` 与 Sokoban 0.3.0 的真实布局、
比较和 replacement 语义直接修改账户 bytes，不把订单树复制进 Rust heap，也不持久化
Map、节点 pointer 或 detached node。

## invariants

- account、root/links/parent/key/sequence base、8-word stride、512 capacity 与 bid/ask side
  都是编译期常量；运行时只携带 2-word key 与 4-word `FIFORestingOrder` payload
- 每个 64-byte slot 精确保存 links、parent/color、price、encoded sequence、trader index、
  base lots、last-valid slot 与 last-valid unix timestamp；索引 one-based，`0` 是 sentinel
- bid 使用 price 与 encoded sequence descending，且 sequence 高位必须为 1；ask 两者
  ascending，且高位必须为 0
- writable、current-program owner、data length、incoming side tag 与完整 tree/free-list
  partition 都在第一次 store 前验证；malformed/readonly/wrong owner 均原子失败
- duplicate key 即使在满树中也只原位替换四个 value words；新 key 经 bump/free-list
  allocation 完整清零并初始化 slot，再执行 bounded Sokoban RB insertion fixup
- effect 在 extraction、target projection、CFG value mapping/canonicalization、static geometry、
  writable IDL 推导和 legacy fail-closed 路径中保持显式；源码入口不展开
  `accDataWordSetAt`
- emitter invocation stack 只保存有界 scalar index 和临时 account-derived pointer；不存在
  persistent pointer、heap tree copy、`Map`/`HashMap` 或无界 allocation

## verification

- Lean guard 钉住 bids `110/114/115/116/117`、asks `4210/4214/4215/4216/4217`、
  stride 8、capacity 512、side flag、零个展开 write 与两个 writable IDL meta
- 直接依赖 `lib-sokoban = 0.3.0` 与 `bytemuck = 1.25.2`；测试按 Phoenix-v1 官方
  `FIFOOrderId` comparator/layout 分别填满 512 bids 与 512 asks，每次插入后比较完整
  32,800 tree bytes 并调用官方 `is_valid_red_black_tree()`
- 满容量 duplicate 原位替换 value 并继续逐字节一致；满容量新 key 返回
  `Custom(0x1003)` 且 bytes 不变；side mismatch、readonly、wrong owner 与 malformed
  topology 均原子失败；Phoenix-v1 profile suite 27/27
- digest `2a24252f935ac912`；assembly 4,528,527 B；ELF 1,448,496 B；IDL 6,647 B
- Surfpool 1.5.0 用 1,432 个 Loader write + deploy + authority transactions 完成本地部署，
  并核对 exact 1,448,541-byte ProgramData；不用 `solana-test-validator`
- 全量 194-job Lean、50 个 SVM build、Mollusk 225/225 与 Anvil 12/12 回归通过

## non-goals

- 不实现 order removal、matching/placement/cancel instruction、runtime capacity、remaining
  accounts 或完整 Phoenix-v1 ABI
- 不开放 persistent raw pointer、heap `Map`、detached node、账户外 tree ownership 或
  无界 transient container
- 不声明公网部署或 Token-2022 extension semantics
