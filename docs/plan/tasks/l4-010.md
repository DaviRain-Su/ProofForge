# l4-010 ATA CreateIdempotent

## objective

`ataCreateIdempotent` 是普通 Lean 包装，抽出成已有 `invoke`。

- 外层：0 payer s+w、1 ata w、2 wallet、3 mint、4 System、5 Token、6 ATA program
- 内层 metas 按官方顺序：payer / ata / wallet / mint / System / Token
- 内层 data：`u8le(1)`（1 字节 packed）
- 负例：缺 payer signer
- 再开一次已存在的 ATA 也成功（idempotent）
- 不再复制发射器
