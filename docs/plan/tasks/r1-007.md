# R1-007 — Bind canonical tagged Borsh input on SVM

## Goal

Bind ordinary Lean `Option` and bounded payload enums to a canonical, SVM-owned Borsh input plan.
The plan must describe the codec once, then let one recursive entry-adapter interpreter handle
bounds, tags, payloads, and exact cursor consumption. It must not add Option/enum recipes to Core
Ops, Components, or the main SVM emitter.

This slice covers **raw SVM input only**. Tagged returns, bounded dynamic arrays, and richer enum
payloads remain fail closed until their wire/resource policies are defined independently.

## Delivered

- `Svm.EntryAdapter.BorshDecode` is a reusable declarative tree for sequence, scalar, Option, and
  enum decoding. `BorshPlan` records fixed invocation-local scalar slots, logical projections, and
  minimum/maximum wire bytes; it contains no account offsets, pointers, or application names.
- The planner recursively combines static records/products/fixed vectors with canonical u8 Borsh
  tags. `Option` uses tags 0/1; enums use their source-order constructor index and reject more than
  256 variants. Inactive payload locals are zeroed before branch selection.
- The entry-adapter codec backend has one recursive cursor interpreter. It performs bounded scalar
  reads, canonical Bool/tag checks, branch-dependent payload decoding, and exact final cursor
  consumption. No tagged case was added to the main `Svm.Emit` instruction emitter.
- SVM IR resolves source projections such as Option tag/payload and enum variant payload fields to
  fixed decoded locals before Core CFG lowering. No heap object or persistent pointer is created.
- Extract now materializes an Option matcher payload as a local only when the branch performs
  further computation. Existing identity matches keep their prior canonical IR and digest, while
  ordinary code such as `some amount => amount + 1` is supported.
- `Examples.Svm.RawEntry` adds ordinary Lean `Option UInt64` and a three-variant enum with zero, one,
  and two `UInt64` payloads. Mollusk covers every valid variant plus invalid tag, truncation, and
  trailing-byte rejection.

The ownership path is:

```text
Core logical Option/enum schema
             │
             ▼
Svm.EntryAdapter Borsh plan
             │ fixed locals + bounded cursor
             ▼
      SVM CFG + codec Emit
```

The existing explicit packed/raw entry plans remain compatibility APIs. New typed parameters use
the schema-derived plan instead of teaching Emit a per-type or per-application recipe.

## Next

R1-008 must define an explicitly named EVM tagged-value ABI policy. Solidity ABI has no native
`Option` or sum type, so EVM must not copy Borsh tags or silently invent an encoding. Tagged
returns and bounded dynamic tails stay closed until their own canonical shape and resource bounds
are specified.
