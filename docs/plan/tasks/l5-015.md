# l5-015 fixed-memory whole bid tree and allocator partition

## objective

增加通用 fixed-stride 账户内 Sokoban red-black tree validator，并接到 Phoenix-v1 bid
allocator。验证器直接遍历账户数据，不把 512–4096 个节点复制到 transient heap，也不依赖
`Vec`、`HashMap` 或持久指针。

## invariants

- account/links/parent/key/sequence base、stride、capacity 和 bid/ask ordering 编译期固定；
  capacity 为 1–4096，短账户在形成 data pointer 前 `Custom(1)`
- runtime root/size/bump/free-list 必须满足 1-based Sokoban allocator envelope
- iterative parent-pointer walk 验证 root black、child↔parent reciprocity、color、red rule、
  strict in-order Phoenix FIFO key、equal black height 和 exact reachable live count
- 固定 4096-bit stack bitmap 拒绝 live cycle/shared child、free-list cycle/duplicate 及
  live/free overlap；live + free 精确覆盖 `[1, bumpIndex)`
- bitmap 位于 4096-byte SVM frame 底部，operand load 完成后复用；validator 不调用 syscall、
  不分配 heap、不复制节点

## path

`ProofForge/Svm/Runtime.lean`, `ProofForge/Svm/Ops.lean`, `ProofForge/Svm/Emit.lean`,

## verification

- Lean static-shape/arity/IR guards覆盖 512/1024/2048/4096 四档，capacity >4096 fail closed
- Mollusk 覆盖 valid tree、fully recycled allocator、ordering、red-red、black-height、
  live/free overlap、free cycle、漏 free slot 和 live count
- 4096-capacity profile 的 4095-node perfect black tree 返回 1，消耗 852,066 / 1,400,000 CU
- `lake build Tests` 194 jobs、50 个 SVM build、Mollusk 205/205、Anvil 12/12 全绿
- digest `53d37673dbf95305`；assembly 2,876,110 B；ELF 936,264 B；IDL 2,752 B
- Surfpool 1.5.0 用 926 个 Loader write + deploy + authority transactions 落入 exact
  936,309-byte ProgramData，并核对完整 ELF；不用 `solana-test-validator`

## non-goals

- 本切片只接 bid allocator；ask/trader whole-tree coverage 留给后续切片
- 不写节点，不开放 runtime base/stride/capacity 或 runtime remaining accounts
- 不把调用期 SVM heap pointer 写入 Phoenix market account
