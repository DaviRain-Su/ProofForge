# l4-001 clock.slot + account-0 signer key

## objective

在现有 Lean 语法上开一条 SDK 表面，不是新 DSL，也不是 `solana-program` 模块克隆。

- `ProofForge.Runtime.clockSlot : UInt64`：抽出后发射 `sol_get_clock_sysvar`，读 40 字节 `Clock` 的第一个 `u64`（物理 slot，不是逻辑 block）。
- `ProofForge.Runtime.signerKey0 : UInt64`：抽出后从 `ACC0_KEY+0` 读指定账户公钥的第一个小端 `u64`。用到该叶子的入口 `needSigner=true`。这是账户 0 的 key，**不是** `tx.origin` / fee payer。
- `unixTime` / 其余 Clock 字段 / 完整 32B key / CPI 本切片不做，fail closed。

宿主定理钉在普通 `def` 上；`clockSlot` / `signerKey0` 是不可约 stub，不假装等于链上值。不声称 `.so` refinement。

## path

`ProofForge/Runtime.lean`, `Ops.lean`, `Extract.lean`, `Emit.lean`, `IR.lean`, `Golden.lean`, `Examples/Svm/Clock.lean`, `Tests/*`, `runtime-tests/solana/tests/clock.rs`

## verification

- `height` 两次 `warp_to_slot` 返回对应 slot，证明不是 ELF 常量
- `stamp` 把当前 slot 写入状态；`get` 读回，不再走 syscall
- `key0` 在 signer 时返回 `pubkey[0..8]` 小端 u64；缺 signer → `Custom(1)`
- 已有合约 Mollusk 不回退
