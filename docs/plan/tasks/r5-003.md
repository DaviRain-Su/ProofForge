# R5-003 — Add bounded static EVM roles

## Goal

Provide reusable role membership and mutation decisions without adding a role-shaped target
instruction, hiding storage writes, or pretending that EVM persistent storage is a dynamic Lean
collection.

## Delivered contract

`Evm.Sdk.Roles.Set2` models one role with exactly two explicit Address slots. `Address.zero` marks a
vacancy. Its compiler-erased helpers decide membership, vacancy, full state, and which literal slot
a grant or revoke should update. Applications continue to own authorization, pause policy, error
terminals, and every State field write.

`EvmStaticCounter` uses the component for immutable-owner-managed operators;
`EvmStaticRoster` uses it for admin-managed writers and independently chooses to reject grants but
allow revokes after close. Both declarations allocate two consecutive Address fields through
`Storage.Static`; neither stores `Set2`, a Vector, a pointer, or a runtime layout object.

Zero grants select `ZeroAddress()`, duplicate grants and nonmember revokes are idempotent, a third
distinct member selects `CapExceeded()`, and unauthorized attempts leave both slots unchanged.

## Compiler boundary

The helpers are pure source policy and inline to existing Address limb comparisons. No
Runtime/Ops/IR/Component/Emit case or hashed-map namespace is added. Dynamic indexed Address views
are not published: the current Address-return OOB-zero branch is not a trustworthy extraction
contract. Consumers expose membership and use explicit raw slots until that shared return boundary
is fixed.

## Evidence

- `Tests.EvmRolesSpec` pins capacity, empty state, static declaration/extracted-slot equality,
  expected role entries, and absence of the unsupported indexed Address views.
- Both contracts use canonical IR digests (`ce10997e74a7972b`, `5994b0ab59e7399b`) and compile
  with solc 0.8.34; deployment bytecode is 6,809 B and 5,804 B.
- Dedicated Anvil matrices cover zero, duplicate, two successful grants, full-set failure,
  membership, nonmember/member revoke, authorization, raw neighboring slots, and closed-roster
  policy. The aggregate gate is 289 Lean jobs and 20/20 Anvil contracts.
