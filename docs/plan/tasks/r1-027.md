# R1-027 — Shared UInt64 integer square root

Date: 2026-08-31
Status: done

## Goal

Add one allocation-free floor integer square root shared by Rust-style `u64::isqrt` policy and
OpenZeppelin's default `Math.sqrt`, without adding a target opcode, floating-point dependency,
host allocation, or emitter recipe.

## Delivered contract

- `Core.Math.UInt64.sqrt` returns the greatest UInt64 `root` such that `root² ≤ input`; zero and
  one return directly. The maximum result is `2^32 - 1`, including at `UInt64.max`.
- The nontrivial branch uses five fixed magnitude probes (32/16/8/4/2), a three-halves initial
  improvement, and six Newton rounds. The loop state is the two-scalar `(estimate, quotient)`
  frame, and the final `min estimate quotient` correction avoids squaring an overshooting
  intermediate value.
- A single mutable estimate was rejected because the legacy extractor classified that recurrence
  as additive `forAccum`. The two-scalar algorithm both caches the next quotient and preserves the
  intended generic `forBody` semantics; a structural guard rejects future accumulation fallback.
- SVM `BatchSizer.capacityRoot` applies the floor to two-dimensional capacity partitioning. EVM
  `EvmPriceBand.quoteRoot` applies it to quote normalization. They share value policy but no state,
  ABI/account geometry, authorization, error vocabulary, or physical layout.

## Boundary

This slice exposes floor root only. Explicit rounding modes, ceiling square root, nth roots,
fixed-point roots, and UInt128/UInt256 root helpers remain fail closed. The implementation does not
silently replace checked arithmetic, allocate a bigint, or invent target-specific instructions.
