# wsm-044 XrplMint mint cap（`cap`）

`cap` JSON key lives on the minter card, same pattern as `halt` / `supp`.
Missing or `0` = unlimited. Not a `State` field. Not Sdk.Map.

`Examples.XrplMint` digest `51d4e64e9830bf58`. Runtime leaves
`flushCap` / `peekCap` (`xflushc` / `xpeekc`); key `cap` at offset 72.
`setCap` is minter-only. mint / mintTo refuse when `supp + amount > cap`.

活网：`setCap(8)` 在 `supp=8` 时 mint 状态码 1；`setCap(9)` 后 `mint(1)`
→ A.bal=2 supp=9 cap=9；B `setCap` 状态码 3。
