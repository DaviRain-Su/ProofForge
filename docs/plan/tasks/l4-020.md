# l4-020 Token SetAuthority / Revoke

## objective

`tokenSetMintAuthority` / `tokenRevoke` 是普通 Lean 包装，抽出成已有 `invoke`。

- SetAuthority：外层 0 current mint authority s、1 mint w、2 new authority r、3 Token
  内层 metas：mint w / current authority s
  data `u8le(6) || u8le(0) || u8le(1) || accKey 2`（35B packed；MintTokens + Some(acc2)）
- Revoke：外层 0 owner s、1 source w、2 pad、3 Token
  内层 metas：source w / owner s；data `u8le(5)`（1B）
  callee 钉死 acc3，与 Set 共用 4 账户表
- 负例：缺 current authority / owner signer
- 不再复制发射器；AccountOwner / FreezeAccount / CloseAccount 类型仍关

## path

`Ops.lean`, `Runtime.lean`, `Extract.lean`, `Golden.lean`,
`Examples/TokenAuth.lean`, `Tests/*`, `runtime-tests/solana/tests/token_auth.rs`

## verification

- TokenAuth Mollusk：SetAuthority 把 mint_authority 改成 acc2；Revoke 清掉 delegate
- 缺 signer → Custom(1)
- Clock digest 不回退
