# R4-002 — EVM-RT-2b typed LOG and custom-error plans

## Goal

Move EVM LOG/custom-error memory geometry out of individual closed effects and into one bounded,
target-owned plan/interpreter without exposing arbitrary opcodes, event signatures, or selectors to
source contracts.

## Delivered contract

- `Evm.LogError.LogPlan` derives LOG0..4 topic count, ABI data-word offsets, and exact data byte
  length. It accepts no more than four topics and four bounded data words.
- `Evm.LogError.ErrorPlan` validates an exact lowercase four-byte selector, derives ABI argument
  offsets after that selector, and derives the exact revert byte length. Arguments are bounded at
  four words.
- `Evm.LogError.Emit` is the sole interpreter for these plans. It consumes already-materialized Yul
  words and indentation only, so it allocates no fresh names and preserves existing emission order.
- Existing NativeFx LOG1, Transfer/Approval LOG3, Insufficient, Unauthorized, ZeroAddress, Paused,
  and CapExceeded effects consume the interpreter. ClosedCall permit uses it for Expired,
  Unauthorized, and Approval as well.

Event/error names, signature hashing, and operand materialization remain in the closed semantic
components. Plan-level LOG0/2/4 coverage does not create a generic source event API.

## Resource and failure boundary

- Topic count, data words, selector syntax, and argument count fail closed before Yul is emitted.
- Data memory is a fixed maximum of 128 bytes. Error data is a fixed maximum of 132 bytes including
  the selector.
- Plans exist only in the compiler. They add no contract runtime allocator, storage write, external
  call, delegatecall/create path, or unbounded bytes value.

## Evidence

- Focused plan/interpreter gates cover LOG0 through LOG4, selector-only/one-word/two-word errors,
  malformed selectors, topic overflow, and bounded-data overflow.
- Full aggregate Lean regression passes 272 jobs after registering the new modules and focused spec.
- All 20 EVM contracts compile and Anvil passes 20/20.
- Refactor output for all 20 contracts is byte-identical in Yul, bytecode, and ABI.
- Ownership and whitespace gates pass.

## Remaining EVM Runtime work

- consolidate payable/receive policy where closed native effects still duplicate shape;
- keep precompile-specific return contracts closed rather than opening arbitrary external calls.
