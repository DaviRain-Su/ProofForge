# l5-014 constant-memory account parent path

## objective

增加通用 fixed-stride 账户内 parent-path reader，并把它接到 Phoenix-v1 bid tree。正常
Sokoban 红黑树操作沿 O(log N) path 工作，不复制 512–4096 个节点，也不依赖 transient
heap、`Vec` 或 visited Map。

## invariants

- account/links base/parent base/stride/capacity/max depth 全部编译期固定
- runtime index/root/bump 必须落在 1-based live-index envelope；短 account 在 pointer formation
  前 `Custom(1)`
- 每步检查 node color、parent index、parent→child reciprocity；self-parent 立即拒绝
- 必须在最多 32 条 edge 内到达 parent/color=0 的 root；root 外 cycle 有界返回 0
- emitter 只保留 current/root/bump/depth 和临时 word，不分配 heap 或复制 node array

## path

`ProofForge/Svm/Runtime.lean`, `ProofForge/Svm/Ops.lean`, `ProofForge/Svm/Emit.lean`,
`Examples/PhoenixV1Profile.lean`, `runtime-tests/solana/tests/phoenix_v1_profile.rs`

## verification

- IR/static-shape guards覆盖 512/1024/2048/4096 四个 profile
- Mollusk 覆盖 root、两侧 child、多 edge、非法 index、错 reciprocity 和 reciprocal cycle
- 全量 `lake build Tests` 194 jobs、50 个 SVM build、Mollusk 203/203 与 Anvil 12/12 通过
- digest `381c728318e7fe26`；assembly 2,509,900 B；ELF 821,576 B
- Surfpool 1.5.0 用 812 个 Loader write + deploy + authority transactions 落入 exact
  821,621-byte ProgramData，并核对完整 ELF；不用 `solana-test-validator`

## non-goals

- 单条 path 不冒充 whole-tree coverage、global ordering、black-height 或 live/free partition
- 不做完整 tree/free-list 扫描，不写节点，不开放 runtime base/stride/capacity
- 不把调用期 SVM heap pointer 写入 market account
