# R1-021 — SVM tagged Borsh return binding

## Goal

Bind the shared fixed tagged-result frame to canonical branch-dependent Borsh return data without
reusing input cursor geometry, allocating a tagged object, or adding tagged recipes to Runtime,
Ops, IR, Component, or the main SVM emitter.

## Delivered

- `Svm.EntryAdapter.BorshReturnPlan` independently describes Option payload widths and enum
  active-payload counts alongside the existing bounded-output policies.
- The output interpreter writes the compile-time maximum frame into bounded stack scratch, checks
  the u8 tag, requires every inactive source lane to be zero, and publishes only the selected Borsh
  prefix: `0` or `1 || payload` for Option, and `ordinal || active UInt64 fields` for enums.
- `Examples.RawEntry` directly echoes ordinary Lean `Option UInt64` and a three-variant payload
  enum. Their input and output plans share only logical source projections; decoder cursor state is
  not reused by the output encoder.

## Boundaries

The initial contract supports a one-limb Option payload and enum constructors containing only
UInt64 fields. Constructed tagged results, richer payloads, and nested tagged output remain fail
closed. The frame is invocation-local stack scratch only; no pointer or heap collection reaches
account state.

## Verification

- Focused Lean guards cover source projection, target plans, canonical identities, scratch bounds,
  CFG frames, and output-interpreter assembly routes.
- RawEntry digest is `21207ff5263a4d4a`; the Loader-v3 ELF is 46,336 bytes.
- Mollusk passes all 20 RawEntry tests, including None/Some and all three enum wire shapes.
- Surfpool 1.5.0 deploys the exact ELF through Loader-v3 in 46 write transactions and verifies the
  resulting ProgramData bytes.

## Next

EVM should bind the same logical frame to an independent Tagged Tuple output policy. Constructed
tagged source values should be opened only after Extract can prove constructor identity and inactive
lane canonicality.
