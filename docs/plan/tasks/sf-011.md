# sf-011 Tree 全树 wf 保持

## 目标

完成 `Examples/Svm/Tree.lean` 从 p-004 切片到 **insert/remove/rotate 保持全树 wf**（在 N 有界设定下）。

## 交付

1. 有界可达性 / 父子互逆 / 颜色与序（按现有 wf 定义能陈述的部分）
2. `insert_wf` / `remove_wf`（可分批）
3. 与 sf-009 索引层定理的接口说明（谁依赖谁）

## 进展（2026-09-02）

- **几何 `wf` 闭包**：`wf_nodes_set` + `paintNode_wf` + `linkLeft_wf` / `linkRight_wf`（`Examples/Svm/Tree.lean`）
- 已有：`init_wf` / `allocNode_wf` / `removeNode_size` / 旋转 size 守恒
- **新增 `rotateLeft_wf`**（`Examples/Svm/Tree.lean`）：`rotateLeft` 成功路径保持几何 `wf`，
  覆盖全部 6 条分支（`innerAddress`/`parentAddress` 是否为 0，父节点挂左/右子）。
  证明前置是「`x`/`y`/`inner`/`parent` 地址落在 `[1, bumpIndex)`」的显式假设
  （几何 `wf` 只给 `≤ bumpIndex`，不排除指针恰好等于 `bumpIndex` 的悬空情形，
  留给 BST/可达性切片收紧）。新增 `wf_nodes_set3` / `wf_nodes_set4`（三/四槛
  `nodes.set` 组合）与 `node_bound_set`（任意一次 `set` 后单槛读值界，不用管
  命中槛是否和之前的 `set` 下标重合）两个私有 kernel 引理支撑。
  `#print axioms` 只依赖 `propext`/`Quot.sound`，无 `sorry`。
- **新增 `rotateRight_wf`**（`Examples/Svm/Tree.lean`）：与 `rotateLeft_wf` 镜像
  （`left`/`right` 互换），同样覆盖全部 6 条分支，假设风格一致（成功 + `wf s` +
  `x`/`y`/`inner`/`parent` 地址界）。直接复用 `rotateLeft_wf` 引入的
  `wf_nodes_set3` / `wf_nodes_set4` / `node_bound_set`，未新增引理。
  已在 `Tests/ProofSpec.lean` 加 `#check`。`#print axioms` 只依赖
  `propext`/`Quot.sound`，无 `sorry`。
- **新增 `insertRoot_wf`**（`Examples/Svm/Tree.lean`）：空树首插路径保持几何 `wf`；
  证明结构与 `allocNode_wf` 同构（bump / free-list 两分支），额外 `root := address`
  不在 `wf` 谓词内故不影响结论。已在 `Tests/ProofSpec.lean` 加 `#check`。
- **新增 `insertNode_wf_root` + `insertNode_value_update_wf`**：`insertNode` 空树分派
  与 duplicate-key 只改 `value` 的几何 `wf` 闭包（后者经 `wf_nodes_set`）
- **恢复 `insertAt_linked_wf` / `insertAt_linked_wf_bump` / `insertAt_linked_wf_free`**
  （`Examples/Svm/Tree.lean`）：`insertAt` 在 `fixInserted` 之前的 **linked** 状态保持几何 `wf`；
  bump / free-list 两分支分别经 `insertAt_linked_nodes_wf`（`wf_nodes_set2`）与
  `vec_set2_get_right` 组合；`insertAt_linked_wf` 按 `freeHead = bumpIndex` 分派。
- **恢复 `insertAt_wf`（黑父路径）**：当父节点 `color ≠ 1` 时 `fixInserted` 为恒等，
  结论归约到 `insertAt_linked_wf_*`。已在 `Tests/ProofSpec.lean` 加 `#check`。
- **新增 `fixInserted_grand0_paint_parent_wf`**：红父 + `grandAddress = 0`（父即 root）
