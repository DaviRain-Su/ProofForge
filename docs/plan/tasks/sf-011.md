# sf-011 Tree 全树 wf 保持

## 目标

完成 `Examples/Svm/Tree.lean` 从 p-004 切片到 **insert/remove/rotate 保持全树 wf**（在 N 有界设定下）。

## 交付

1. 有界可达性 / 父子互逆 / 颜色与序（按现有 wf 定义能陈述的部分）
2. `insert_wf` / `remove_wf`（可分批）
3. 与 sf-009 索引层定理的接口说明（谁依赖谁）

## 进度

已落地：

* `reachable` / `parentInv` / `bstLocal` / `rootBlack` + `init_*` 定理
* 指针有界辅助：`vec_set_ne` / `ptr_bound_set` / `ptr_bound_set_unalloc` / `wf_of_nodes`
* `set_value_wf` / `paintNode_wf`
* `rotateLeft_meta` / `rotateRight_meta`（size/bump/free 守恒）
* `rotateLeft_wf` / `rotateRight_wf`（已分配轴/孩子/内孩前提下的全指针 `wf` 保持）
* `insertRoot_wf` + `insertNode_wf_empty` / `insertNode_wf_update`（空树臂 + 改 value 臂）
* `linksAllocated` + `fixInserted_wf`（父/祖父/叔节点非哨兵链接均落在已分配区时，染色与四种紧凑重接线保持 `wf`）
* `insertAt_bump_linked_wf` / `insertAt_free_linked_wf` + `insertAt_wf`（bump/free allocator、父链接、fixup 全成功路径）
* `insertNode_wf_insertAt`（已约化到 `insertAt` 的非空 miss 臂）
* sf-009 `OrderedMapModel` 接口注记（`AssocIndex` ↔ Tree 几何）
* `linksAllocated` 删除接口 + `transplantNode_wf` / `rotateLeftDelete_wf` /
  `rotateRightDelete_wf` / `moveSuccessor_wf` / `fixDeleted_wf`
* `removeNode_wf`：从成功返回地址已分配、非哨兵链接已分配、输入 size 非零，
  推出 successor / replacement / replacementParent 边界，并组合
  transplant-or-move → delete fixup → root 染黑 → release 全管线

SF-7 的 insert/remove/rotate **几何 `wf` 保持已闭合**。任务整体仍待补：
`reachable` / `parentInv`（以及需要时的 `bstLocal` / `rootBlack`）在操作下的保持。

## 进展（2026-09-02）— rotation / wf 细节

- **几何 `wf` 闭包**：`wf_nodes_set` + `paintNode_wf` + `linkLeft_wf` / `linkRight_wf`（`Examples/Svm/Tree.lean`）

- **新增 `rotateLeft_wf`**（`Examples/Svm/Tree.lean`）：`rotateLeft` 成功路径保持几何 `wf`，
  覆盖全部 6 条分支（`innerAddress`/`parentAddress` 是否为 0，父节点挂左/右子）。
  证明前置是「`x`/`y`/`inner`/`parent` 地址落在 `[1, bumpIndex)`」的显式假设
  （几何 `wf` 只给 `≤ bumpIndex`，不排除指针恰好等于 `bumpIndex` 的悬空情形，
  留给 BST/可达性切片收紧）。新增 `wf_nodes_set3` / `wf_nodes_set4`（三/四槛
  `nodes.set` 组合）与 `node_bound_set`（任意一次 `set` 后单槛读值界，不用管
  命中槛是否和之前的 `set` 下标重合）两个私有 kernel 引理支撑。
  `#print axioms` 只依赖 `propext`/`Quot.sound`，无 `sorry`。
- **新增 `rotateRight_wf`**（`Examples/Svm/Tree.lean`）：与 `rotateLeft_wf` 镜像
