# wsm-013 XRPL-ALPHANET：XLS-0102 host 表

## objective

活着的公开网是 `https://alphanet.xrpl.org`（network_id **21337**，rippled
`3.3.0-rc1` `alphanet` 分支，`SmartContract` 已开）。不是已经挂掉的
nerdnest 21465。

本 Bedrock 镜像的 host 名（`get_current_ledger_obj_field` / `get_ledger_sqn` /
`compute_sha512_half`，view `i64`）**不是** 这条网的 ABI。AlphaNet 是
XLS-0102：

| Bedrock 本地 | AlphaNet |
|---|---|
| `get_current_ledger_obj_field` | `home_le_field` |
| `get_tx_field` | `tx_field` |
| `get_ledger_sqn() → i32` | `ldgr_index(ptr,len) → i32`（写 4 字节小端） |
| `compute_sha512_half` | `sha512_half` |
| `sfContractAccount` 524315 | **524320** |
| view export `i64` | **必须 `i32`**（否则执行期 return type mismatch） |

CLI：`pf build --target xrpl-alphanet`（别名 `alphanet`）。默认 `--target xrpl`
仍是 Bedrock 本地，digest 不变。

## 不做什么

- 不把 AlphaNet 放进 CI（公共 RPC 会 502 / `noCurrent`）
- 不改 Bedrock 本地 host 名
- 不声称主网 `deployable`

## verification

- `#pf_xrpl_alphanet_emit_check Examples.Counter`：WAT 含 `home_le_field` /
  `tx_field` / `ldgr_index` / `sha512_half`，view `get` 是 `i32`
- Bedrock Counter digest 仍是 `e029f72296e320be`
- 本地用创世种子对 AlphaNet `ContractCreate` 已 `tesSUCCESS`
  （合约 `rfpCfY2V4kYCVyP58GurVxYFJVMRA4PtVD`）。无参 `initialize` 返回
  `tecBYTECODE_REJECTED` / VM **-18**（`INDEX_OUT_OF_BOUNDS`：缺
  `Parameters[0]`）。带 UINT64 的 `ContractCall` 卡在公共 RPC `noCurrent`，
  不把 skip 当绿。
