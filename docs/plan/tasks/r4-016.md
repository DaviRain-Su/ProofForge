# R4-016 — Preserve typed source custom-error frames

## Goal

Compile ordinary parameterized Lean `Except.error` constructors into reusable target-neutral error
frames, then let EVM derive matching Solidity custom-error selectors, argument words, and ABI JSON
without adding one Runtime/Component/Emit recipe per application error.

## Delivered contract

- `Core.Ops.ErrorFrame` preserves one constructor name plus ordered named scalar fields through
  target projection and CFG. The initial safe source surface is one through four explicit, unique
  `UInt64` constructor fields; wider, anonymous, implicit, recursive, polymorphic, and oversized
  payloads fail closed instead of silently becoming `name()`.
- EVM validates that descriptor once, derives `name(uint64,...)` and its ABI metadata from the same
  ordered fields, materializes each word, and delegates physical selector/revert geometry to the
  existing bounded `LogError.ErrorPlan` interpreter.
- SVM deliberately erases typed payloads to the existing constructor-name program error. This
  preserves current Solana behavior without importing EVM ABI geometry or adding an SVM opcode.
- Zero-field source constructors remain the existing `.errorNamed` path, preserving selector-only
  EVM reverts and existing SVM error codes.

No heap, allocator, map, pointer, hidden storage write, application-specific component, or raw
revert-data surface is added.
