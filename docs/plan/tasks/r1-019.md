# R1-019 — EVM bounded dynamic return binding

## Goal

Bind top-level shared bounded values to canonical standard-ABI returndata without reusing calldata
tail geometry, allocating a target collection, or adding collection recipes to Runtime, Ops, IR,
or the main CFG emitter.

## Delivered

- `Evm.Codec.DynamicOutputPlan` independently describes bounded-array and packed-byte output
  policy. It owns the fixed source-frame types and a canonical identity that includes array element
  ABI type, capacity, and String validation policy.
- EVM IR retains the output plan separately from `DynamicInputPlan`; return types and IR digests
  therefore preserve rules that are not represented in a Solidity function selector.
- The codec output interpreter publishes one canonical standard-ABI dynamic result:
  `offset=32 || length || active words` for arrays, or
  `offset=32 || length || packed active bytes || zero padding` for bytes/String.
- Packed output memory is explicitly zeroed before active bytes are staged. String runs the strict
  Unicode-scalar UTF-8 gate at the publication boundary, including for a source value constructed
  entirely from scalar parameters.
- `Examples.Evm.EvmBounded` consumes the generic plans for `uint16[]`, `bytes`, and `string`; no
  application type, selector, or policy entered the target codec.

## Boundaries

This slice supports top-level bounded returns whose array element is one scalar limb. Nested
dynamic values, tagged dynamic returns, wide/aggregate elements, dynamic constructors, and frames
above 64 source words remain fail closed. The capacity-sized source frame is never returned, and
inactive slots do not enter returndata.

## Verification

- Focused Extract → EVM IR → CFG/Yul guards cover independent output plans, source-frame counts,
  ABI JSON result types, output capacity checks, zero padding, and output-side UTF-8.
- EvmBounded digest is `dace199d3c7ca718`; solc 0.8.34 emits 3,668 bytes of deployment bytecode
  and a 1,813-byte ABI JSON file.
- Anvil accepts empty/partial/full bounded-array, bytes, and String round trips plus a scalar-built
  valid String. It rejects an over-capacity constructed result and malformed output-only UTF-8,
  including stray continuation, overlong, surrogate, truncated, and above-U+10FFFF encodings.
