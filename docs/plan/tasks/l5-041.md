# L5-041 — Add a key-based ordered cursor to account storage

## Goal

Provide the reusable ordered traversal primitive needed by Phoenix `CancelAll` without collecting
orders in a heap `Vec`, retaining account-data pointers, or adding a Phoenix-specific top-level op,
IR node, or main emitter case.

## Delivered

- Added `AccountStorage.Query.fifoCursor` alongside existing fixed-geometry read/find/validate
  queries. The descriptor owns account/root/links/key/stride/capacity/side geometry, read-only
  effects, account inference, operand arity, well-formedness, and canonical target-IR spelling.
- The dynamic cursor is only `(hasCursor, price, sequence)`: `hasCursor=0` returns the logical first
  one-based slot; `hasCursor=1` returns the strict upper-bound slot; empty/end returns zero.
- Every call restarts at the account-resident root. Callers retain only the scalar key across a
  removal, so RB rotations and predecessor transplants do not require a persistent node address.
- Traversal is bounded to 64 checked links. Every selected one-based index is checked against the
  static capacity, and the complete root/links/key envelope is checked against account `data_len`.
  Cycles, out-of-range links, invalid `hasCursor`, and short accounts fail closed.
- Ask and bid reuse the existing FIFO comparator: ascending price/sequence for asks and descending
  price/encoded-sequence for bids. Equal-price FIFO order and non-existent in-between keys use the
  same strict upper-bound algorithm.
- Added only thin Runtime/Ops/extractor constructors. All geometry must remain extraction-time
  constant; a negative extraction fixture rejects runtime-selected account geometry.
- Added read-only `cursorBid512` / `cursorAsk512` profile probes. Mollusk exercises empty, first,
  strict next, equal-price ordering, end, invalid cursor mode, malformed cycles, and re-query after
  a two-child removal changes tree topology.

Persistent state remains fixed-capacity account bytes with one-based indexes and a zero sentinel.
The implementation allocates no heap `Map`/`Vec`, copies no node, exposes no raw pointer, and adds
no top-level SVM operation or main-emitter branch.
