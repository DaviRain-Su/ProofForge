# R3-020 — Compose Rent-aware System and PDA creation

## Goal

Provide the Solana SDK-shaped “create this fixed-size account at the current rent-exempt minimum”
policy without hard-coding lamports, introducing runtime-selected account geometry, or adding a
second System instruction backend.

## Delivered contract

- `Svm.Sdk.System.createRentExempt space` composes the existing compile-time
  `Sysvar.Rent.minimumBalance` query with the existing fixed-account `createAccount` facade.
- `System.AsciiSeed.createRentExempt seed space` and
  `Pda.Ascii.createRentExempt seed space` apply the same policy to the already-validated
  create-with-seed and invoke-signed paths.
- `space` is a `Nat` and must be compiler-static because the current Rent query and account/CPI
  geometry are extraction-time contracts. Only the resulting lamports word is dynamic at runtime.
- The facade reads the invocation's current Rent sysvar. It does not bake a default Rent value,
  expose a native pointer, allocate host memory, or persist a descriptor.
- No Runtime leaf, Ops/IR/Component/Emit recipe, account table, resize/realloc/free/close behavior,
  or runtime-selected geometry was added.

## Evidence

- Focused Lean specs pin all three facade forms and verify the generated CreateAccount instruction
  data contains the existing `rentExemption 16` value.
- Create and CreatePda are independent non-seeded and PDA consumers. Their Mollusk tests replace
  the default Rent sysvar and verify exact payer debit plus new-account lamports, 16-byte space,
  and current-program owner.
- Create target-IR digest `6ee1719e05c53163`; assembly 24,373 B; ELF 9,584 B; ELF SHA-256
  `395c5a479f2b2f5321a2431ac9f646d4c50235e432f25bbf6af912cd14cfa608`.
- CreatePda target-IR digest `ef405b71cc52f3ec`; assembly 35,382 B; ELF 14,408 B; ELF SHA-256
  `5803d04649af7f699ec2e3d66ee404d94ada91a44491d6cbd0d758d19608f5dc`.

Rent-aware resize and close/reassign lifecycle policy remain separate because they require
ownership, current data length, lamports flow, and failure-order contracts beyond CreateAccount.
