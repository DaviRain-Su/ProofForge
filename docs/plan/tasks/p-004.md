# p-004 removeNode size 守恒 + wf 良构谓词第一批切片

## objective

**removeNode_size**（`Examples/Svm/Tree.lean`）：`removeNode s k = .ok (t, a) →
t.size + 1 = s.size`，无条件成立——`(a-1)+1 = a` 对 UInt64 模 2^64 恒真，
所以不需要「树非空」前置。支撑引理（全部 private）：paintNode /
linkLeft / linkRight / transplantNode / rotateLeftDelete /
rotateRightDelete / moveSuccessor / fixDeleted 的 size 守恒，加上
`ite_except_ok_inv`（绕开 split 在巨型项上的 motive elaboration）与
`size_ite` / `sub_add_ite` 同态。

**wf 谓词第一批切片**（分配器几何 + 指针有界）：

```
wf s := size ≤ 4 ∧ 1 ≤ bumpIndex ≤ 5 ∧ freeHead ≤ 5 ∧ freeHead ≤ bumpIndex
        ∧ (∀ a ∈ [1, bumpIndex)：节点的 left/right/parent ≤ bumpIndex，color ≤ 1)
```

- `init_wf`：初始状态良构
- `allocNode_wf`：allocNode 保持 wf——bump 分支游标 +1 有界、free-list
  分支弹出链头（`left` 即 next-free，≤ bumpIndex 由旧 wf 给出）；槽位
  单射性（`slot_inj`：`(a-1)%4` 在 `[1,5)` 上单射）+ Vector set-ne/set-self
  处理「新节点 vs 旧节点」分叉

全部只依赖标准公理 `propext` / `Quot.sound`。
