# l2-003 本机算出 disc 与 layout marker

## objective

`discHexOf` / `layoutMarkerHex` 不再挂名表。算法与 Mollusk 夹具同一预镜像：

- disc = `sha256("proof-forge-solana-v1:" ++ ixName ++ "(" ++ sig ++ ")")` 前 8 字节，小端 u64
- layout marker = `sha256("proof-forge-solana-layout-v1:" ++ layoutSig)` 前 8 字节，大端 u64

Lean 4.31 无内核 SHA-256。实现放在本机纯函数里，能进 `#guard`。禁止 FFI 当链上后端。

新方法名、新字段表不必改 `IR.lean`。

## path

`ProofForge/Sha256.lean`, `ProofForge/IR.lean`, `Tests/*`, `docs/modules/ir.md`

## verification

- 已登记 disc / marker 与旧表逐字相同
- 未挂过的名字也能算出，且与 Python/Rust `sha256` 前 8 字节一致
- `#pf_build` Counter / Pair / Flag / Maybe digest 不变
- Mollusk 不回退
