# l4-019 clockEpoch

## objective

`clockEpoch` 是普通 Lean 叶子，抽出后走已有 `sol_get_clock_sysvar`，读 `Clock.epoch`（偏移 16）。

- 同一条 40 字节缓冲；slot 仍在 0
- 宿主 `@[irreducible]` stub，值是 0
- `unixTime` / `epoch_start_timestamp` 仍 fail closed（有符号 i64）
- 完成定义：两次 `warp_to_slot` 返回不同 epoch，证明不是 ELF 常量
