# l5-023 exact fifth Phoenix trader registration

## objective

按 Sokoban 0.3.0 的账户内 bump allocator 与 red-black insertion，把最小 128-seat trader
tree 从 canonical 四节点状态推进到五个 distinct keys。第五次插入既覆盖 black-parent
无修复路径，也覆盖 black-uncle LL/LR/RL/RR rotation；全程只读写固定账户 slot index，
不构造 heap tree/Map。

## invariants

- 输入必须是 84,944-byte `(512,512,128)` shape，trader header 为
  `padding=0,size=4,bump=5,free=5`，且 complete tree/allocator validator 必须先证明
  root、links、parent reciprocity、颜色、key ordering 与 live/free partition canonical
- address 4 必须是上一切片产生的唯一 red leaf；新 key 必须与四个 existing keys 都
  distinct，搜索结果只能是 missing child 或 address 4 的 missing child
- bump allocation 固定返回 address 5，并原子发布 `size=5,bump=6,free=6`；slot 5 的
  18 words 全部覆盖，既有四个 TraderState 保持逐字节不变
- black parent 路径只填 missing link；red parent 路径按 black/null uncle 精确执行
  LL/LR/RL/RR local rotation/recolor，最上层 black root 地址保持不变
- 成功路径精确保留 27 个 external-account writes，结果 complete validator 返回 1；
  duplicate/malformed 以 `Custom(0x1001)` fail closed，readonly/wrong owner 以 `Custom(1)`
  失败，所有失败保持完整账户 bytes 不变
- 所有持久引用仍是 one-based address 与 `0` sentinel；不保存 raw pointer，不使用
  `Map`/`HashMap`、detached node、heap tree copy 或无界 allocation

## verification

- Lean guard 钉住 complete four-word-key validator、bounded indexed reads、slot 5 的完整
  18-word overwrite 与成功分支精确 27 writes
- Mollusk 从 first-through-fourth entry points 构造六种 canonical address layout；八个
  byte-for-byte case 覆盖 black-parent insertion、LL/LR/RL/RR black-uncle repair，以及
  red grandchild 两侧的 missing-child 路径；四个 existing TraderState 保留，结果均满足
  `bodyEntryCount=5` 与 `traderTreeValid=1`
- 四个 duplicate keys、malformed topology、readonly、wrong owner 均原子失败；profile
  suite 20/20
- digest `9140326aef66cbdc`；assembly 4,378,054 B；ELF 1,399,096 B；IDL 5,061 B
- Surfpool 1.5.0 用 1,383 个 Loader write + deploy + authority transactions 完成本地部署，
  并核对 exact 1,399,141-byte ProgramData；不用 `solana-test-validator`
- 全量 194-job Lean、50 个 SVM build、Mollusk 218/218 与 Anvil 12/12 回归通过

## non-goals

- 不实现第六个/一般 key insertion、free-list reuse、delete fixup 或 runtime capacity
- 不开放 persistent raw pointer、heap `Map`、detached node 或账户外 tree ownership
- 不声明公网部署、runtime remaining accounts、Token-2022 extension 或完整 Phoenix-v1 ABI
