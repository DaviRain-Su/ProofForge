# l4-012 Token MintToChecked / BurnChecked

## objective

`tokenMintToChecked` / `tokenBurnChecked` 是普通 Lean 包装，抽出成已有 `invoke`。

- Mint：外层 0 authority s、1 mint w、2 dest w、3 Token
  内层 metas：mint / dest / authority；data `u8le(14) || u64le amount || u8le decimals`
- Burn：外层 0 owner s、1 source w、2 mint w、3 Token
  内层 metas：source / mint / authority；data `u8le(15) || u64le amount || u8le decimals`
- decimals 本切片钉死为 6
- 负例：缺 authority / owner signer
- 不再复制发射器

## path

`Ops.lean`, `Runtime.lean`, `Extract.lean`, `Golden.lean`, `Examples/TokenMint.lean`, `Tests/*`, `runtime-tests/solana/tests/token_mint.rs`

## verification

- TokenMint Mollusk：mint 增加 dest 余额和 mint supply；burn 减少两者
- 缺 signer → Custom(1)
- TokenXfer digest 不回退
