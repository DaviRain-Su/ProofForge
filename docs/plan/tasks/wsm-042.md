# wsm-042 owner-gated mint（XrplMint）

编译期 genesis AccountID 才能 `mint`。`State` 仍只有 `bal` 槽，persist 不会
把 owner 三叶写到对方卡。任何人都能 `pay`。不是 XRP Payment，不是 Sdk.Map。

`Examples.XrplMint` digest `2cf692a113f709c7`。活网：A `mint(5)`；B `mint(1)`
→ 状态码 3；A `pay(B,2)` → A=3 B=2；`pause` 后 mint/pay 状态码 4，卡不变；
`unpause` 后再 `pay(B,1)` → A=2 B=3；B `pause`/`unpause` → 状态码 3；A `mintTo(B,4)`
→ B=7，B `mintTo` 拒；pause 时 `mintTo` 状态码 4；B=`u64Max` 后再 `mintTo(B,1)`
→ 状态码 1，A 仍 2；A `burn(1)` → A=1；`burn(9)` 状态码 1；pause 后 `burn` 状态码 4。
`halt` 不进用户 `bal`。
