# l4-002 封闭 system.transfer

## objective

一条具名 recipe，不是通用 CPI。Lean 里写 `systemTransfer amount`，抽出后发射固定三账户 + `sol_invoke_signed_c`。

账户表（外层）：

| i | 角色 | signer | writable | data |
|---|---|---|---|---|
| 0 | payer | yes | yes | 0 |
| 1 | recipient | no | yes | 0 |
| 2 | System Program（全零 pubkey） | no | no | 0 |

内层 System 指令：`u32le(2) || u64le(lamports)`，12 字节。syscall 是 `sol_invoke_signed_c`，signer seeds 为空。payer 签名来自外层交易特权，不是 PDA。

宿主 `systemTransfer` 是不可约 stub。不声称 `.so` refinement。不做 Token / PDA / remaining accounts / 动态 program id。
