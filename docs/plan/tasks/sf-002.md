# sf-002 Queue pop / peek / initialize / 往返

## 目标

把 BoundedQueue 模型代数收口到「可宣称 L2 done」。

## 交付

1. `mQueuePop_singleton_clear`：size=1 → pop 后 count=0、head=0
2. `mQueuePop_multi_advance`：size>1 → head 走 `mQueueNext`、count-1、返回槽值
3. `mQueuePeek_eq` / empty peek 哨兵
4. `mQueueInitialize_zero_headers`（若 SDK initialize 只写两 header）
5. `mQueuePush_pop_roundtrip`（空队列或单元素场景即可先钉）
6. 矩阵 Queue 行标 done；SF-1b → done

## 非目标

不证 RbMap；不扩 Ops/Emit。

## 验收

同计划 §5 公共门 + Queue 行为用例在 Tests 或 `#check` 层可引用。
