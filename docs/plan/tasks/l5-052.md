# L5-052 — Route Phoenix cancellation through a static FIFO facade

## Goal

Remove the remaining Phoenix-v1 cancel-all and cancel-up-to positional book/trader geometry from
contract source. Keep Phoenix's concrete layout in `Examples`, expose a reusable statically shaped
FIFO cancellation facade from the SVM SDK layer, and preserve the existing account-resident,
fixed-capacity execution model without extending the emitter.

## Delivered

- Added `ProofForge.Svm.FifoCancel.Source` as the source-facing facade for the existing bounded
  cancellation component. Contract code now calls `begin`, `cancelSide`, `cancelUpTo`, aggregate
  result queries, and `finish`; the facade expands a compile-time `FifoCancel.Config` into the
  existing positional runtime hooks during extraction.
- Extended static source normalization to erase FIFO descriptors, including projected Nat/String
  recorder fields. Only trader indexes, tick/search/cancel limits, and component scalar results
  remain dynamic. A cancel-up-to claim policy must reduce to a compile-time Bool or extraction
  fails closed.
- Added named bid/ask cancel configurations to `Examples.PhoenixV1.Layout`. Phoenix-specific book
  selection, trader balance fields, collateral math, lot/header words, recorder limits, offsets,
  and capacities remain in `Examples`; `ProofForge/Svm` contains no Phoenix profile or magic
  offsets.
- Rewrote all four official cancel routes around the named layout and FIFO facade. Complete
  storage validation, trader lookup, book size, market sequence, lot size, cancellation passes,
  released-funds queries, and claim policy no longer reconstruct positional geometry in handler
  code.
- Added the static Phoenix audit sink descriptor used by cancellation. The positional recorder
  begin/append/finish helpers are deliberately left for the next slice, where they can consume the
  same descriptor without changing cancellation again.
- Added no Core/SVM opcode, top-level IR node, component variant, CFG case, or main-emitter case.
  Persistent state remains fixed account bytes with one-based indexes and the `0` sentinel; there
  is no heap `Map`/`Vec`, copied node, persistent pointer, runtime-selected geometry, or unbounded
  traversal.

The source boundary is now:

```text
Phoenix layout + audit profile (Examples)
        │ static bid/ask cancel Config
        ▼
FifoCancel.Source (ProofForge/Svm)
        │ compile-time descriptor erasure
        ▼
existing FifoCancel component → AccountStorage + BatchRecorder backend
```
