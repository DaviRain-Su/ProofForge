# l5-037 Composed Phoenix ReduceOrderWithFreeFunds state transition

## objective

用稳定的 `AccountStorage` vocabulary 组合最小官方 512/512/128 profile 的 bid/ask
`ReduceOrderWithFreeFunds` 账户状态语义，验证上层合约功能不再要求新增业务专用的
SVM Op、IR constructor 或主 Emit case。

## invariants

- account 0 signer Pubkey 经 Key4 bounded find 得到 one-based trader index；未注册 trader
  fail closed，order 中的 `trader_index` 必须精确相等
- selected trader tree 与 bid/ask tree 都先执行 complete tree/free-list validator；随后 FIFO
  find missing 按官方语义成功返回 `0`，不会执行 collateral arithmetic 或 store
- `removed = min(requested, resting)`；partial 只写原 order slot 的 quantity，full 组合既有
  `rbMapRemove`，zero request 对非零 resting order 保持 tree 与 balances 不变
- ask 把 `removed` 从 trader base locked 移到 base free；bid 按
  `price × tickSize × removed / baseLotsPerBaseUnit` 从 quote locked 移到 quote free
- divisor、两次乘法、locked subtraction 与 free addition 均在第一条 account store 前
  preflight；wrong trader、overflow/underflow、malformed topology、readonly/wrong owner 原子失败
- source 暴露 `accDataWordAtOneBased` / `accDataWordSetAtOneBased` 薄接口；descriptor 的
  account/base/stride/capacity 仍必须 extraction-time fixed，`0` sentinel 在 backend 内拒绝
- 持久状态只保存账户内 one-based index 与 `0` sentinel；不创建 heap Map、node copy、
  detached allocation 或 persistent pointer

## implementation

- `AccountStorage.Query.readWordOneBased` 与 `Call.writeWordOneBased` 通过 Runtime/source
  decoder 暴露；顶层 `ValKind`、`OpExt`、`Svm.IR.Op` 与主 emitter 不增加 case
- `reduceAskFreeFunds512` / `reduceBidFreeFunds512` 只组合 complete validator、Key4/FIFO
  find、one-based field read/write 和 FIFO map removal
- bid arithmetic 直接读取官方 MarketData account words 104/105；TraderState 与
  FIFORestingOrder 字段使用官方 18-word / 8-word fixed stride

## verification

- Lean IR gate 检查两个方法包含完整 validator、两类 bounded find、one-based reads/writes、
  partial quantity store 与 full map removal；IDL market meta 必须 writable
- Mollusk 覆盖 ask zero/partial/full、bid exact quote unlock、missing no-op、wrong trader 与
  multiplication overflow atomicity；full removal 后 complete ask validator 仍返回 `1`
- source digest `fdec3afb265a542`；assembly 6,548,227 B；ELF 2,081,880 B；IDL 9,011 B
- `lake build Tests`、50 个 SVM registry build、Mollusk、Anvil 12/12 与 Surfpool 1.5.0
  Loader-v3 smoke 全绿

## next migration

tag 4 的 vault→trader SPL Token 提款，避免把协议解码、事件、Token CPI 和 RB mutation
