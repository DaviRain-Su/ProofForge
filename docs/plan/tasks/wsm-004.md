# wsm-004 WASM 家族第二条链：NEAR Protocol Lean → WAT → `.wasm`

## objective

叠在 XRPL 的 wsm-002 上。产物是 **`.wasm`**，不是 Rust 源。Lean 直接 lowering
到 WAT，组装器锁定 `wat2wasm 1.0.41`。链间差异由 `Wasm/Near/Host` +
`Wasm/Near/Emit` 拥有：

1. host import 表：`env.{input,register_len,read_register,storage_read,storage_write,value_return,panic_utf8}`
2. 存储布局：ASCII 字段名 key，8-byte LE KV
3. 入口 ABI：无 C 参数；`env.input` 恰好 `8 * paramCount` LE bytes；
   `value_return` 8-byte LE。**不是 JSON ABI**（历史仓 `near-wasm-raw-u64-v1`）。

digest 域 `near-raw-u64|`，与 `xrpl-bedrock|` 故意不同。`deployable=false`。

## 不做什么

- 不经过 rustc / `near-sdk` / cargo
- 不复用 XRPL `host_lib` / `home_le_field` / `set_data` / Data sfield
- 不发明通用 `pf` import 模块；不把 wasmtime 当链宿主
- 不声称 testnet / mainnet / formal refinement
