# p-003 asVal 巨石拆分 + Tree 结构不变量证明

## objective

两条线：

**编译侧**：`Extract/Decode.lean` 里 1198 行的单个 `asVal` partial def 拆出
`asValNamed`（`constName` 分派臂，约 1127 行：SVM/EVM runtime op 词汇表），
以 `mutual` 保持递归；`asVal` 保留形状分派与归约/字面量臂（73 行）。
全部 163 个 SVM 产物（`.so`/`.s`/`.idl.json`）与 EVM 产物拆分前后逐字节一致。

**证明侧**：`Examples/Svm/Tree.lean` 的 8 个结构不变量定理（N=4 Sokoban RB-tree）：

- `init_state`：初始 root/size/bumpIndex
- `setHead_roundtrip` / `setAt_roundtrip`：写读一致
- `allocNode_size`：成功路径 `size+1` 且有界 `≤ 4`
- `rotateLeft_size` / `rotateRight_size`：**旋转不改变节点数**（不分配不释放）
- `rotateLeft_root` / `rotateRight_root`：根要么不变，要么换成旋转轴孩子

全部只依赖标准公理 `propext` / `Quot.sound`。

## 语义边界说明

EVM hashed-map 的 put/get 代数引理**不能**在当前层证明：`evmMapGetAddr256` /
`evmMapSetAddr256` 是 `@[irreducible]` 宿主占位（get 恒返回 0），证明会变成
「证 stub 而非链」。这批改证全可计算的 Tree 合约；map 语义需要真实的
SLOAD/SSTORE 模型后才能证。
