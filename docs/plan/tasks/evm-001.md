# evm-001 Evm.IR + keccak selector

## objective

平行于 `ProofForge.IR` 的 EVM 程序形状。storage slot 从 0 连号，每槽一个 UInt64。`initialize` 是 constructor。其余方法是 ABI entry。selector = `keccak256(name + "(" + uint64×N + ")")` 前 4 字节，小写 hex。

从已抽出的 `IR.Program` 转换。拒绝：`clockSlot` / `signerKey0` / `systemTransfer`、非 8 字节槽、`_tag` Option 双叶。不扩现有 `IR.Program`。

digest = 规范化文本的 FNV-1a 64，与 Solana digest 故意不同。

## path

`ProofForge/Evm/Keccak.lean`, `ProofForge/Evm/IR.lean`, `ProofForge/Evm/Golden.lean`, `Tests/EvmSpec.lean`

- `keccak256 ""` = `c5d24601…`
