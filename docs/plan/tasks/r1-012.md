# R1-012 — Target-neutral bounded-vector operations

## Goal

Turn `Core.Value.BoundedVec` from a boundary carrier into a reusable, capacity-preserving source
component without introducing a collection opcode or pretending that SVM and EVM share physical
memory, account, or storage layout.

## Delivered

- `Core.Value.BoundedVec` now provides canonical-frame checks, capacity/size/empty/full queries,
  active-prefix lookup, checked replacement, push, pop, and clear semantics.
- Every operation keeps one compile-time `Vector` frame. Push/pop change only the `UInt32` logical
  length and fixed scalar leaves; there is no `Array`, hash table, pointer, allocator, or implicit
  growth.
- `getD` is a compiler-erased scalar lookup facade. SVM Borsh and EVM ABI adapters lower its
  runtime index over their existing fixed decoded locals to bounded scalar selects.
- The lowering lives in target codec adapters because Borsh locals and ABI locals are target-owned.
  Core Ops, target extension Ops, Components, CFG, and both Emit vocabularies gain no Vector case.
- Dynamic reads currently require a one-limb scalar element. Aggregate/wide elements and mutation
  writeback remain fail closed until their typed leaf/update contract is explicit.

## Allocation contract

The Lean `Vector` is source/extraction representation only. On SVM, canonical Borsh decoding still
uses a fixed invocation-local scalar frame and never persists a pointer into account data. On EVM,
canonical ABI decoding still uses a bounded Yul local frame and does not allocate a storage object.
Persistent SVM containers continue to use account bytes/indices; persistent EVM containers continue
to use slots or hashed namespaces.

## Verification

- `Tests.CoreCollectionsSpec` checks valid/malformed frames and every source operation.
- Its `CompileProbe.readOr` passes Extract, SVM Borsh binding and assembly emission, and EVM bounded
  ABI binding and Yul emission from the same source helper.
- Existing codec tests continue to own malformed Borsh/ABI byte matrices; this slice does not add a
  third shared wire format.

## Next

Add bounded bytes/string specialization and a target-neutral bounded key/value semantic contract.
Keep SVM account-persistent ordered maps and EVM hashed maps as separate physical bindings. Add
aggregate/wide dynamic-vector leaves and mutation writeback only with explicit resource and storage
contracts.
