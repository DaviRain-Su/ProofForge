# R4-004 — EVM-RT-2d typed closed ecrecover contract

## Goal

Replace the permit path's hand-written ecrecover STATICCALL assumptions with one target-owned
typed plan/interpreter, while keeping precompile address and memory geometry closed and exposing
no arbitrary STATICCALL or precompile surface to source contracts.

## Delivered contract

- `Evm.Precompile.Plan` pins the only supported precompile to address `0x01`, the canonical
  128-byte `hash | v | r | s` input frame, and the exact 32-byte recovered-address output.
- `Plan.wellFormed` requires STATICCALL success, exact returndata size, and a nonzero result. Any
  changed address, geometry, or missing gate fails before Yul is returned.
- `Evm.Precompile.Emit` is the sole interpreter. It reuses `CallResult.Emit.staticWord` for the
  call, success, exact-size, and word-load spelling, then owns the ecrecover-specific nonzero gate.
- `ClosedCall.Emit` permit recovery consumes this interpreter instead of spelling address `1`,
  frame sizes, and fail-closed checks inline.

The exact-size gate closes an EVM-specific stale-memory hazard: invalid ecrecover input can
succeed with empty returndata, leaving the fixed output area unchanged. Loading that memory
without requiring `returndatasize() == 32` could misread input residue as the recovered signer.

## Resource and failure boundary

- The plan has compile-time fixed input/output geometry and allocates no dynamic memory or
  persistent state.
- Input-frame construction remains with the closed permit consumer; only the validated call and
  result contract move into the reusable target component.
- Other precompiles, arbitrary addresses, arbitrary STATICCALL, delegatecall, create, unbounded
  returndata, source Ops, and IR vocabulary remain unsupported.

## Evidence

- Focused `Tests.EvmPrecompileSpec` and aggregate `Tests` pass; the aggregate contains 280 jobs.
- All 20 registered EVM contracts compile with solc 0.8.34 and Anvil passes 20/20.
- Only Token Yul and bytecode change, adding the exact-returndata fail-closed gate; every other
  Yul/bytecode/ABI artifact is byte-identical, and all IR registry digests remain unchanged.
- Ownership and whitespace gates pass.
