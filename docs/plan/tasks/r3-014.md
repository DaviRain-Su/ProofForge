# R3-014 — Stable SVM sysvar SDK facade

## Goal

Keep application source above raw SVM Runtime stubs while reusing the existing target-owned
Clock, EpochSchedule, and Rent host contracts byte-for-byte.

## Delivered contract

- `Svm.Sdk.Sysvar.Clock` exposes slot, epoch, and unix timestamp.
- `Svm.Sdk.Sysvar.EpochSchedule` exposes slots per epoch.
- `Svm.Sdk.Sysvar.Rent.minimumBalance` accepts a compile-time account-data length, preserving the
  existing extraction and checked multiplication contract.
- Clock, Epoch, and Rent independently consume the facade. Their extracted IR digests and emitted
  syscall paths remain unchanged.
- The facade is entirely `pf_inline`: it adds no syscall, Runtime leaf, Op, IR node, component,
  emitter recipe, scratch allocation, or persistent representation.

## Limits

The remaining Clock/EpochSchedule fields, signed timestamp interpretation, sliced generic sysvar
reads, Instructions sysvar, stack height, and remaining compute units remain explicit Runtime
backlog. Runtime-selected Rent lengths are not silently accepted.

## Verification

- Focused Lean guards prove SDK-to-Runtime delegation and preserve all three syscall families.
- Existing Clock/Epoch/Rent extraction and emitter suites keep their registered IR digests.
- The integrating commit records the aggregate Lean and registered SVM build gates.
