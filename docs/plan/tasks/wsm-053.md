# wsm-053 每人一张卡 freeze（`lock`）

## objective

公开 AlphaNet 不能造 PDA、不能写合约金库（-22）、不能 emit Payment（-196）。
下一刀仍走 caller-card：在用户自己的 `ContractData` 上加编译期 JSON key `lock`。

`Examples.XrplLock` digest `d2c4673c64a8d0c`。

- Runtime：`xrplFlushLock` / `xrplPeekLock`（arity 1 / 3）
- 发射：`xflushl` / `xpeekl`；key `lock` ASCII 在 96，值 scratch 112
- 错误码 5 = `errorNamed "frozen"`（不是 paused 4）
- `pay` 进出都拦：caller lock 或 dest lock 非零 → 5，卡片不变
- `credit` 不拦；`freeze`/`unfreeze` 只写 caller 卡

## 不做什么

- 不开 `Sdk.Map` / `Sdk.Payments`
- 不发明 PDA / 关联账户工厂
- 不把 `lock` 放进 `State`（persist 会拷到 dest 卡）
