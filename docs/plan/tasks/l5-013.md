# l5-013 Phoenix-v1 verifier Surfpool deployment

## objective

把 P5 `PhoenixV1Profile` 当前 ELF 通过 Surfpool 1.5.0 的真实 Upgradeable Loader-v3
transaction path 部署到本地 offline Surfnet。部署门与 Phoenix 共用同一个参数化 smoke，
不引入或回退到 `solana-test-validator`。

## path

`runtime-tests/surfpool/smoke.sh`, `runtime-tests/surfpool/txtx.yml`,
`runtime-tests/surfpool/runbooks/deployment/main.tx`, `.github/workflows/ci.yml`

## verification

- `instant_surfnet_deployment = false`；buffer/create/write/deploy/authority 都走交易
- `PhoenixV1Profile` 716,344 B ELF 通过 708 个 Loader write transactions 部署
- confirmed deploy signature、36-byte executable Program account、716,389-byte ProgramData
  与完整 ELF bytes 一致
- 泛化后的默认 Phoenix 路径也重新通过，仍为 3,389 个 write transactions

## non-goals

- 不联系 devnet/testnet/mainnet，不声明公网部署
- 不把 Mollusk 当部署证据
- 不改变 P5 verifier 的账户读取语义或扩大完整 Phoenix-v1 兼容声明
