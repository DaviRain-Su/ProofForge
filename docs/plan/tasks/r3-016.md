# R3-016 — bounded transient `sol_log_data` binding

Date: 2026-08-29
Status: done

## Goal

Connect the reusable invocation-local byte writer to Solana's official logging Runtime without
adding another top-level opcode recipe or exposing heap pointers and syscall descriptors to source
programs.

## Delivered contract

- `Svm.Sdk.Transient.Bytes.logData` publishes the active byte prefix as exactly one
  `sol_log_data` field. Capacity remains compile-time geometry while runtime length controls the
  published slice.
- The target-owned Bytes component reuses the shared lifecycle active/capacity validation before
  constructing any pointer.
- A 16-byte syscall-adjacent `SolBytes` descriptor is materialized as `[payload address, length]`
  in disjoint deep scratch. The payload is not copied and the descriptor is not a source value,
  generic IR value, or persistent account value.
- Malformed zero-capacity geometry fails the existing static component gate; stale and
  capacity-mismatched handles retain the existing `0x1213` terminal error.

This slice deliberately covers one bounded binary field only. Multi-field logs, text formatting,
pubkey/numeric helpers, stable typed events, and bounded return-data get/set are separate Runtime
contracts rather than hidden extensions of this API.

## Consumer and evidence

`Examples.MemoryOps.bytesLogData` appends one little-endian u64 and one checked trailing byte,
publishes the nine-byte active prefix, finishes the handle, and returns the independent scalar
length. Focused evidence includes:

- Lean guards for canonical component lowering, static malformed geometry, source effect order,
  exact descriptor stores, and the `sol_log_data` syscall;
- Mollusk 11/11 with exact `Program data: iHdmVUQzIhGq` and simultaneous 9-u64 return data;
- canonical MemoryOps digest `328ed73565005d33`, 114,438-byte assembly, and 38,432-byte ELF;
- no new generic Ops/IR/CFG/main-emitter case and no persistent pointer or host collection.

Surfpool remains the deployment qualification environment; this slice adds no Test Validator path.
