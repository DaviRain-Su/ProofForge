# l6-001 bounded SVM transient heap model

## objective

按 Solana 官方 Rust entrypoint allocator 建立调用期 heap 的可执行边界模型，而不是把
Rust `Vec`/`Box` 或普通 Map 误当成无限、持久内存。它与 Phoenix/Sokoban 的账户内
fixed-capacity allocator 是两块不同地址空间。

## invariants

- heap 从 `0x300000000` 开始；默认 32 KiB，compute-budget 上限 256 KiB，按 1 KiB 请求
- 第一 machine word 保存 bump；分配从 frame end 向下，按 power-of-two alignment 向下对齐
- subtraction 饱和；覆盖首 word 或 frame 外状态时 OOM/fail closed
- deallocation 是 no-op；每次 invocation 结束后全部 transient allocation 一起消失
- 不允许把 heap pointer 写进账户；持久树仍使用账户内 1-based index/offset

## path

`ProofForge/Svm/Heap.lean`, `Tests/SvmHeapSpec.lean`, `docs/modules/svm.md`

## verification

- 常量、frame envelope、alignment、首次/连续 allocation、exact capacity、OOM、no-op free guards
- `lake build Tests.SvmHeapSpec`

## non-goals

- 本切片不开放 source-level `Vec`/`Box`/Map，也不向 emitter 暴露任意 raw pointer
- 不把 heap 用于 Phoenix-v1 account tree traversal 或持久节点
- 不自动请求大于 32 KiB 的 transaction heap frame
