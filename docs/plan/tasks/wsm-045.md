# wsm-045 XrplMint compile-time spender allowance（`allw`）

`allw` JSON key lives on the *caller* card. Granted to a compile-time
spender (wallet B). Not a Map: one spender, one key. Source of
`takeFrom` is the compile-time minter card.

`Examples.XrplMint` digest `baf279204f02cfc6`. Runtime leaves
`flushAllw` / `peekAllw` (`xflusha` / `xpeeka`); key `allw` at offset 92.
`approve` writes caller `allw`. `takeFrom` is spender-only.

活网：A `approve(2)`；A `takeFrom` 状态码 3；B `takeFrom(A,1)` → A.bal=1
B.bal=8 allw=1；欠额 `takeFrom(9)` 状态码 1；pause 后 `takeFrom` 状态码 4。
