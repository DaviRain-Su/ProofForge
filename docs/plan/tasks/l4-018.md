# l4-018 Token ApproveChecked / Freeze / Thaw

## objective

`tokenApproveChecked` / `tokenFreezeAccount` / `tokenThawAccount` 是普通 Lean 包装，抽出成已有 `invoke`。

- Approve：外层 0 owner s、1 source w、2 mint r、3 delegate r、4 Token
  内层 metas：source w / mint r / delegate r / owner s
  data `u8le(13) || u64le amount || u8le decimals`（10B packed）
- Freeze：外层 0 freeze authority s、1 account w、2 mint r、3 Token
  内层 metas：account w / mint r / authority s；data `u8le(10)`（1B）
- Thaw：同 Freeze 账户表；data `u8le(11)`（1B）
- decimals 本切片钉死为 6
- 负例：缺 owner / freeze authority signer
- 不再复制发射器；SetAuthority / 未检查的 Approve(4) 仍关
