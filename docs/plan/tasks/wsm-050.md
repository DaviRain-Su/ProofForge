# wsm-050 burn 切回 caller 再 persist

`peekHaltLit` / `peekSuppLit` 会把 persist owner 切到 minter。`burn`
restore caller 后再 `peekOwnerLimbs caller`，避免把 minter `$bal` 写到
别人卡上。不是 Map。

`Examples.XrplMint` digest `be33d6f3c772422d`。

活网：B `burn(1)` → B.bal=7，A.bal 仍 1，supp=8。
