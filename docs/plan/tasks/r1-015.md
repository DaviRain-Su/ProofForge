# R1-015 — Bounded bytes / UTF-8 source contracts

## Goal

Give dynamic bytes and strings distinct logical source identities instead of claiming that generic
`BoundedVec UInt8` already determines Borsh or Solidity ABI encoding. Keep allocation and physical
wire policy out of the shared layer.

## Delivered

- `Core.Value.BoundedBytes capacity` and `BoundedString capacity` use a compile-time fixed UInt8
  frame plus a checked `UInt32` active length. No target pointer, heap object, or runtime-selected
  capacity is present.
- BoundedBytes delegates lookup/set/push/pop/clear/size/full semantics to the existing BoundedVec
  contract rather than duplicating another collection implementation.
- The shared UTF-8 validator accepts Unicode scalar encodings and rejects truncation, overlong
  forms, UTF-16 surrogate encodings, invalid continuation bytes, and values above U+10FFFF.
  BoundedString checked construction and well-formedness reuse that validator.
- `Core.Codec.Schema.boundedBytes` and `.boundedString` preserve distinct logical identity and
  resource accounting through Profile and Extract.

## Target boundary

This slice intentionally rejects both schemas in SVM and EVM target adapters. The next target
slices must bind BoundedBytes to Borsh `Vec<u8>` / ABI `bytes` and BoundedString to Borsh `String` /
ABI `string`, with independent cursor/tail validation. Until then, no target can silently lower the
new source types as generic arrays. No Ops, Component, IR, or Emit recipe was added.

## Verification

`Tests.CoreCollectionsSpec.ByteAndStringSemantics` covers finite byte operations and UTF-8 ASCII,
two-, three-, and four-byte success plus overlong/surrogate/truncated/out-of-range failures.
`Tests.CoreCodecSpec` and `Tests.ProfileSpec` cover literal-capacity extraction, resource usage,
dynamic-capacity rejection, and explicit SVM/EVM fail-closed target gates.

## Next

Implement the SVM Borsh byte/string plan and emitter first, including strict UTF-8 validation for
String, then implement the standard EVM ABI byte/string tail plan without sharing physical layout.
