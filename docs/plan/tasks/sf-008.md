# sf-008 Allocator alloc/free 模型往返

## 目标

在 AccountWords 上解释 one-based allocator：alloc 满返回 0；free 后可再 alloc 同一槽（自由表语义与 SDK 一致的那一版）。

## 交付

1. `mAlloc` / `mFree`（`ProofForge/Svm/Sdk/AllocatorModel.lean`；亦镜像于
   `StorageModel.lean`，对齐 `Allocator.alloc` / `Allocator.free` 守卫与写序）
2. `mAlloc_full_zero` / `mAlloc_full_noop`；`mAlloc_free_alloc_same` /
   `mFree_then_mAlloc_same`（bump→free→alloc 同槽；有效 free 后沿自由表头
   alloc 取回同一槽，在 `AllocWords` 不相交假设下）
3. bump/freeHead 打包/解包事实 + 空 freelist bump 路径叙事；几何 L1 复用
   `packed_cursor_high` / `slot_low_u32`（`Storage.lean`）与
   `mFreeAt` / `mFree_valid_links` / `mFreeAt_freeHead` 支撑 L2 往返

## 非目标

任意 key 形状；跨账户 allocator。

## 验收

SF-5a → **done**（模型 + 满/invalid 守卫 + free→alloc 同一槽 L2 定理）。
