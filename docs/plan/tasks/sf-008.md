# sf-008 Allocator alloc/free 模型往返

## 目标

在 AccountWords 上解释 one-based allocator：alloc 满返回 0；free 后可再 alloc 同一槽（自由表语义与 SDK 一致的那一版）。

## 交付

1. `mAlloc` / `mFree`（或 SDK 现名镜像） — **done**（`StorageModel.lean`，镜像 `Allocator.alloc` / `Allocator.free` 守卫与写序）
2. `alloc_full_zero` — **done**（`mAlloc_full_noop`）；`alloc_free_alloc_same` — **todo**（需 allocator wf + 字段不相交引理）
3. bump/freeHead 几何 L1 复用已有 cursor 定理并补缺口 — **partial**（`packed_cursor_high` in `Storage.lean` Proofs；L2 free→alloc 往返仍开）

## 非目标

任意 key 形状；跨账户 allocator。

## 验收

SF-5a → partial（模型 + 满/invalid 守卫定理已落地；free→alloc 同一槽待补）。
