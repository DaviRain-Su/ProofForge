# sf-008 Allocator alloc/free 模型往返

## 目标

在 AccountWords 上解释 one-based allocator：alloc 满返回 0；free 后可再 alloc 同一槽（自由表语义与 SDK 一致的那一版）。

## 交付

1. `mAlloc` / `mFree`（或 SDK 现名镜像） — **done**（`StorageModel.lean`，镜像 `Allocator.alloc` / `Allocator.free` 守卫与写序）
2. `alloc_full_zero` — **done**（`mAlloc_full_noop`）；`alloc_free_alloc_same` — **done**（`mFree_then_mAlloc_same`：有效 free 后沿自由表头 alloc 取回同一槽）
3. bump/freeHead 几何 L1 复用已有 cursor 定理并补缺口 — **done**（`packed_cursor_high` / `slot_low_u32` in `Storage.lean`；`mFreeAt` / `mFree_valid_links` / `mFreeAt_freeHead` 支撑 L2 往返）

## 非目标

任意 key 形状；跨账户 allocator。

## 验收

SF-5a → **done**（模型 + 满/invalid 守卫 + free→alloc 同一槽 L2 定理 `mFree_then_mAlloc_same`）。
