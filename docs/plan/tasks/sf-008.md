# sf-008 Allocator alloc/free 模型往返

## 目标

在 AccountWords 上解释 one-based allocator：alloc 满返回 0；free 后可再 alloc 同一槽（自由表语义与 SDK 一致的那一版）。

## 交付

1. `mAlloc` / `mFree`（`ProofForge/Svm/Sdk/AllocatorModel.lean`）
2. `mAlloc_full_zero`；`mAlloc_free_alloc_same`（bump→free→alloc 同槽，在 `AllocWords` 不相交假设下）
3. bump/freeHead 打包/解包事实 + 空 freelist bump 路径叙事

## 非目标

任意 key 形状；跨账户 allocator。
