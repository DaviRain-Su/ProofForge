# R5-004 — Extract reusable EVM pausable policy

## Goal

Move pause semantics out of the broader Access helper without introducing a pause-shaped opcode,
hidden storage write, magic slot, or application recipe. The component must be reusable with owner,
role, or application-specific authorization and must preserve existing EVM artifacts.

## Delivered contract

`Evm.Sdk.Pausable` owns the canonical explicit `UInt8` flags (`running = 0`, `paused = 1`),
fail-closed `isRunning` / `isPaused` predicates, replacement-value transitions, and the existing
closed `Paused()` violation terminal. The application owns the state field, authorization, event
policy, and literal field update. Unknown flag values are neither running nor canonically paused,
so guarded operations fail closed.

`Evm.Sdk.Access` retains its old pause names as compatibility delegates but now owns only access
policy. `TwoStepCounter` and `Credits` consume `Pausable` directly while independently retaining
stored-owner/two-step and map-backed ledger policy.

## Compiler boundary

All helpers are `pf_inline` source policy. Extraction now recognizes marked helpers returning
UInt8/UInt16/UInt32 as scalar helpers, matching its existing UInt64/Bool contract. This generic
narrow-scalar rule is the only compiler change: there is no Pausable name check and no new
Runtime/Ops/IR/Component/Emit case.

Reentrancy is deliberately not represented by this module. A sound guard must order a lock storage
write before an external CALL and clear it after the call/result path. Ordinary returned State does
not prove that ordering, so ReentrancyGuard remains fail closed until explicit effect sequencing or
a guarded-call Runtime contract owns that invariant.

## Evidence

- `Tests.EvmPausableSpec` pins canonical flags, invalid-state behavior, transitions, compatibility
  aliases, two consumers, and their canonical registry digests.
- Focused extraction preserves the TwoStepCounter/Credits IR digests (`3b08dde14972e728`,
  `2cdeb3504c14ed59`).
- Fresh pre/post builds are byte-identical for both contracts' Yul, ABI JSON, and bytecode. Their
  deployment bytecode remains 4,038 B and 5,385 B.
- Existing Anvil suites own the authorization, pause/unpause, blocked-call, and storage-atomicity
  behavior matrices. The aggregate gates pass 293 Lean jobs, all 20 EVM builds, and Anvil 20/20.

Typed Paused/Unpaused event declarations remain part of the generic event surface backlog rather
than being encoded as another closed Pausable recipe.
