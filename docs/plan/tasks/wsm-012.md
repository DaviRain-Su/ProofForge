# wsm-012 XRPL-VEC-1：编译期命名槽 `xs_0`…`xs_2`

## objective

见 [xrpl-sdk-gap.md](../analysis/xrpl-sdk-gap.md) VEC-1。本镜像
`set_data_array_element_field` 调用 trap（`tecWASM_REJECTED`），不能当 Vec
物理层。定长表走已有 `set_data_object_field`，JSON key 是编译期字面量
`xs_0` / `xs_1` / `xs_2`。

- `Examples.Xrpl.XrplVec.State` 三个 UInt64 槽，不是 Lean `Vector`
- `setAt` 用嵌套 `if index = 0/1/2` 选槽；越界 → overflow 状态码 1
- 不新增 host、不改 wasm v0 子集、不叫 `Storage.Vec`

## 不做什么

- 不接 `set_data_array_element_field`
- 不引入运行时长度、无界 Array、动态 key 字符串
- 不做 Map / 用户 ContractData
