# wsm-039 counted forAccum unroll + cross-wallet TwoStep

WASM v0 still has no wasm `loop`. `Wasm.IR` now unrolls:

- literal `indexGet` / `indexSet` → named slots `name_i`
- `forAccum` bound 1..8 → nested `addU64`
- `forBody` / runtime index stay rejected

`Examples.XrplTab` digest `95e92ed0121f53e9` is four named slots plus
`setAt(index, value)` (two UINT64s). Extractor still cannot round-trip
`Vector.set` inside `Except`. The unroll is the IR gate for a later Vector
example.

`Examples.XrplHand` digest `5c6813950576cdda`: second wallet deploys onto
genesis's ContractData card (`accountLit` genesis), `propose`s genesis,
genesis `accept`s. Live `hand.sh`. Not Sdk.Map.
