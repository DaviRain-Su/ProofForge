# wsm-078 本地 else-if 双向锁：A cancel / B cashB

## objective

Dual timelock written as else-if guards (`if !cond then .error`):

- A `lockIn` moves 5 onto contract `esc`, `due = ledgerSqn + 2`
- A `cancel` before due returns esc
- after due A cancel returns 1; only wallet B `cashB` (burns esc+supp, 192 drops)
- early B cash returns 1; A cashB returns 3

Uses `Gate.ok` / `Gate.u64Max`. Not `&&`. Not Rust `?`.
Zero wasm params. Not `Sdk.Payments`. Not `Sdk.Map`.
Not XRPL EscrowCancel. Public still host -22 and tefBAD_AUTH.
