# e-rt-001 环境 + value + Addr20 + ETH + event

## objective

E-RT 整包，不拆叶。见 [05-evm-coverage-slices.md](../../research/05-evm-coverage-slices.md)。

- 环境：`evmTimestamp` / `evmChainId` / `evmSelf` / `evmCallValue` / `evmSelfBalance`；超 UInt64 revert
- Addr20：三叶 `evmCallerW0/W1/W2`、`evmSelfW0/W1/W2`（w2 仅低 4 字节）。8 字节 `evmCaller` 保留
- `evmDeposit amt`：`eq(callvalue(), amt)`；该入口 payable
- `evmSendEth w0 w1 w2 amt`：组装 20B，`call(..., value)`，失败 revert
- `evmLogTipped amt`：LOG1 topic=`Tipped(uint64)`
- 有 payable 入口则去掉全局 `callvalue` 守卫，非 payable 入口本地守卫
- SVM 发射器拒全部新叶/效应
- Examples.Evm.TipJar + Anvil：chainid、deposit 精确 value、错 value revert、sendEth 改余额、log、caller 三叶

## 不做

Window；`clockSlot`→`NUMBER`；完整九叶 Principal；任意 CALL。
