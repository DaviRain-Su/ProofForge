# l5-017 complete Phoenix registered-trader tree validation

## objective

按 Phoenix v1 / Sokoban 0.3.0 的账户布局原位验证四档 registered-trader tree，包括
32-byte Pubkey ordering 和 allocator partition；不把节点复制进 heap、Map 或其他动态容器。

## invariants

- 十二个官方 `(book, seats)` profile 选择编译期固定的 trader base、18-word stride 和
  128–8321 capacity
- Pubkey 按 Rust `[u8; 32]` unsigned byte lexicographic order 严格递增，而不是按四个
  little-endian `u64` 比较
- root/color、child-parent reciprocity、red rule、equal black height、cycle/shared-child、
  exact reachable live count 均 fail closed
- free list 无 cycle、duplicate 或 live overlap，并精确覆盖 `[1, bumpIndex)` 中全部非 live slot
- 调用期只用固定 8321-bit bitmap 和 64-entry traversal stack；账户中只保留官方 slot index，
  不保存 SVM pointer

## verification

- Lean/assembly 门覆盖十二个静态 intrinsic、四个 Pubkey limb 的 `be64` byte-order lowering、
  固定 bitmap/stack 和 free-list loop
- Mollusk 覆盖 byte-order trap、duplicate key、错误 parent、live/free overlap、free cycle；
  profile suite 11/11
- 最大 8321-capacity allocator 的 8191-node perfect black tree + 130 free slots 返回 1，
  消耗 1,344,959 / 1,400,000 CU
- `lake build Tests` 194 jobs、50 个 SVM build、Mollusk 209/209、Anvil 12/12 全绿
- digest `6d8e6cbb2d5dd163`；assembly 3,703,126 B；ELF 1,194,760 B；IDL 3,110 B
- Surfpool 1.5.0 用 1,181 个 Loader write + deploy + authority transactions 落入 exact
  1,194,805-byte ProgramData，并核对完整 ELF；不用 `solana-test-validator`

## non-goals

- 不写 trader/order 节点，不开放 runtime remaining accounts
- 不把 transient bump heap 当持久 allocator，不声明完整 Phoenix-v1 instruction 兼容或公网部署
