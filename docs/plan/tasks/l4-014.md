# l4-014 Token InitializeAccount3 / CloseAccount

## objective

`tokenInitAccount` / `tokenCloseAccount` 是普通 Lean 包装，抽出成已有 `invoke`。

- Init：外层 0 owner s、1 未初始化 Token 账户 w、2 mint r、3 Token
  内层 metas：account w / mint r；data `u8le(18) || accKey 0`（owner = 账户 0 公钥，33B）
- Close：外层 0 owner s、1 source w、2 dest w、3 Token
  内层 metas：source w / dest w / owner s；data `u8le(9)`（1B）
- 负例：缺 owner signer
- 不再复制发射器；`CpiWord.accKey i` 拷外层账户 i 的 32B key

## path

`Ops.lean`, `Runtime.lean`, `Extract.lean`, `Emit.lean`, `Golden.lean`, `Examples/TokenAcc.lean`, `Tests/*`, `runtime-tests/solana/tests/token_acc.rs`

## verification

- TokenAcc Mollusk：init 把 165B Token 账户写成 owner=acc0、mint=acc2；close 把 0 余额账户 lamports 退回 dest
- 缺 signer → Custom(1)
- TokenMint digest 不回退
