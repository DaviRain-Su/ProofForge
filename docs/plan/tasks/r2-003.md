# R2-003 — SVM-RT-2b signer-tail and return-data staging

## Goal

Extend the bounded SVM scratch plan into the remaining fixed CPI geometry instead of retaining
seed-entry and return-data offsets inside individual emitter recipes.

## Delivered contract

- `Scratch.SignerSeedTail` names the copied static seed bytes, aligned bump byte, descriptor array
  including the trailing bump descriptor, and one signer group. Ordinary invoke and dynamic signed
  self-CPI both consume this plan.
- Static ASCII seeds occupy the typed copied-byte region. State/account key and account-data seeds
  continue to reference their fixed sources directly and therefore add no copied bytes, while each
  still receives one descriptor.
- `Scratch.ReturnDataStaging` names the fixed 32-byte caller program-id and 8-byte return payload
  window used by `sol_get_return_data`. The existing exact-eight-byte success policy is unchanged.
- All layout derives through `Plan.alloc`; the emitters consume typed `Region` handles and no longer
  calculate signer-tail ends or return-data offsets locally.

This is target runtime geometry, not a public source container. It adds no Ops, IR, Component, or
main-emitter recipe and does not make return data dynamic.

## Resource and lifetime boundary

- Signer tails remain inside the existing 1,024-byte CPI scratch bank and fail before emission on
  OOM. Seed descriptors are fixed 16-byte Solana C ABI records.
- Return staging is the existing 40-byte deep-scratch window and remains invocation-only. It is not
  live across another syscall.
- Plans contain compile-time offsets and byte counts only. They cannot hold an sBPF pointer, account
  offset, heap object, `Map`, or persistent state.

## Evidence

- Focused scratch guards cover exact fit, OOM, empty/non-copied/mixed multi-seed layouts,
  alignment, descriptor placement, and exact return staging.
- Full aggregate Lean regression passes 269 jobs.
- All registered SVM programs were assembled before and after the refactor; generated assembly is
  byte-identical after excluding random keypair JSON files.
- Ownership and whitespace gates pass.

## Remaining R2/R3 work

- bounded Token-2022 TLV cursor and extension semantics;
- source-facing invocation-local bounded Vec/byte-writer/codec-buffer SDK over the transient heap;
- no persistent pointer, runtime-selected account geometry, or unbounded container support.
