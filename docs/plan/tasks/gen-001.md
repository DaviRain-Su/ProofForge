# gen-001 Expr → 操作序列

## objective

从 `init` / `increment` / `get` 的 elaborated `Expr` 认出 v0 操作（load field、checked add、ctor、ok/error），写进 `IR.Method.ops`。发射 overflow 路径必须以抽出的 `checkedAddU64` 为准，不能只靠方法名。

## context

docs/01-prd.md 竖切之后才是通用；docs/03-technical-spec.md Profile

## path

SolanaLean/Ops.lean, SolanaLean/Extract.lean, SolanaLean/IR.lean, SolanaLean/Emit.lean, Tests/ExtractSpec.lean

## verification

`increment` 抽出含 `checkedAddU64`；改成无保护加法则 extract 失败或不再发射 `0x1001`。
