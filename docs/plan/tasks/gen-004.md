# gen-004 单账户 UInt64 表达式编译器

## objective

抽出器按白名单递归下降 `Expr`，不再只认 Counter 三种整函数形状。发射器按 `Val`/`Op` 生成 load/checked-add/checked-sub/store/return。第二个合约 `decrement` 必须抽出并汇编，且与 Counter 共用同一套 Extract/Emit。

## 语言面（本刀一次做完）

拒绝：无守卫加减、`Nat`、`IO`、其它字段名、递归。
