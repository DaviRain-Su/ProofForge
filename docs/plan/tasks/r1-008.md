# R1-008 — Bind EVM Tagged Tuple v1 input

## Goal

Define an explicitly named EVM ABI policy for ordinary Lean `Option` and bounded payload enums.
Solidity ABI has no native sum type, so this policy must not copy Borsh or let Emit infer a tag
shape. It must produce reusable physical input plans, selectors, canonical guards, projections,
and structured ABI JSON without adding source Ops or type-specific main-emitter instructions.

This slice covers **EVM input only**. Tagged returns and bounded dynamic tails remain fail closed.

## Policy and ownership

`ProofForge EVM Tagged Tuple v1` uses fixed standard-ABI tuples:

- `Option<T>` → `(bool present,T value)`; `present=false` requires every payload word to be zero.
- bounded UInt64-payload enum → `(uint8 tag,uint64 p0,...)`; `tag` is the source constructor
  ordinal, the tuple has enough lanes for the largest constructor, and every inactive lane is zero.

The fixed shape avoids dynamic offsets and ambiguous encodings. `Evm.Codec.AbiInputPlan` owns ABI
word types, source projections, and declarative tag guards. EVM IR uses the same plan to flatten
logical inputs before Core CFG lowering; the emitter only renders generic word/tag rules. Core
continues to own logical schema and does not contain ABI words or Borsh tags.

```text
Core logical Option/enum schema
             │
             ▼
Evm.Codec Tagged Tuple v1 input plan
             │ words + projections + canonical guards
             ▼
       EVM CFG / Yul / ABI JSON
```

No storage slot, application name, contract policy, new Ops case, or type-specific Emit branch is
part of the plan. Richer enum payloads fail closed until Extract has an unambiguous fixed source
representation for them.

## Coverage

`Examples.EvmCtx` uses the same logical Option and zero/one/two-UInt64 payload-enum shapes as the
SVM tagged fixture, but receives the independent fixed EVM tuple encoding. Lean guards cover
selectors, physical parameter words, source projection, generic Yul canonicality checks, ABI JSON,
and tagged-return rejection. Anvil covers all valid variants plus out-of-range tags, noncanonical
Bool, absent Option payload, and inactive enum lanes.
