# p-002 第一批 kernel 证明：合约性质定理

## objective

在合约文件内（`Examples/*`）写普通 `theorem`，kernel 检查与编译走同一
digest 主语。第一批 15 个定理：

**Counter**（`Examples/Counter.lean`）
- `increment_ok`：成功路径新值恰为 `s.value + d`，返回值等于新状态值
- `increment_ok_bound`：单调性（guard 保证不回绕）
- `decrement_ok` / `decrement_ok_le`：精确后置条件 + 单调性
- `scale_zero` / `scale_ok` / `divide_zero_error` / `modulo_zero_error`

**Capped**（`Examples/Evm/Capped.lean`）
- `mint_supply_within_cap`：**cap 不变量**——进入时 `supply ≤ cap`，则 mint
  任何返回结果（含全部 revert 路径）保持 `supply ≤ cap`
- `mint_supply_effect`：supply 只增不减

**Token**（`Examples/Evm/Token.lean`）
- `transfer_preserves_supply` / `transferFrom_preserves_supply` /
  `approve_preserves_supply`：转账与授权不增发不通缩
- `mint_supply_effect` / `burn_supply_effect`：supply 只按精确量变化

全部只依赖标准公理 `propext` / `Quot.sound`（`#print axioms` 审计，见
`Tests/ProofSpec.lean` 头注），无 `sorryAx`、无 `Classical.choice`。
