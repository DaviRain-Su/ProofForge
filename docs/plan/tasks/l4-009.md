# l4-009 Token TransferChecked

## objective

`tokenTransferChecked amount decimals` 是普通 Lean 包装，抽出成已有 `invoke`。

- 外层：0 authority s、1 source w、2 mint、3 dest w、4 Token program
- 内层 metas 按官方顺序：source / mint / dest / authority
- 内层 data：`u8le(12) || u64le amount || u8le decimals`（10 字节 packed，不是 bincode）
- decimals 本切片钉死为 6
- 负例：缺 authority signer
- 不再复制发射器
