# l5-022 exact fourth Phoenix trader registration

## objective

按 Sokoban 0.3.0 的账户内 bump allocator 与 red-black insertion，把最小 128-seat trader
tree 从任意 canonical 三节点地址布局推进到四个 distinct keys。三节点树必为 black root
加两个 red leaves，因此第四次插入固定走 red-uncle recolor；全程只写固定账户 slot index，
不构造 heap tree/Map。

## invariants

- 输入必须是 84,944-byte `(512,512,128)` shape，trader header 为
  `padding=0,size=3,bump=4,free=4`；complete tree/allocator validator 必须先证明 root、
  两个 red leaf、parent reciprocity、颜色、key ordering 与 live/free partition canonical
- 新 key 必须与三个 existing keys 都 distinct；六种 address assignments 覆盖 root/left/right
  的所有排列，测试的新 key 合并覆盖 left outer/inner 与 right inner/outer 四个区间
- bump allocation 固定返回 address 4，并原子发布 `size=4,bump=5,free=5`；slot 4 的
  18 words 全部覆盖，既有三个 TraderState 保持逐字节不变
- selected red parent 获得 address 4 child；两个 existing leaves recolor black，root 保持
  black 且地址不变。成功路径精确保留 23 个 external-account writes
- account-resident tree validator 与 parent-path intrinsic 必须保存 walked ABI 的 `r7`
  instruction-data base；内部 fixed-memory traversal 不能破坏后续参数读取
- duplicate/malformed 以 `Custom(0x1001)` fail closed；readonly/wrong owner store 以
  `Custom(1)` 失败；所有失败保持完整账户 bytes 不变

## verification

- Lean guard 钉住 complete four-word-key validator、bounded indexed reads、slot 4 的完整
  18-word overwrite 与成功分支精确 23 writes
- Mollusk 从 first + second + third entry points 构造六种 canonical address layout，对完整
  84,944-byte output 做 byte-for-byte 比较；四个 key 区间都覆盖，existing TraderState 保留，
  且每种结果都满足 `bodyEntryCount=4` 与 `traderTreeValid=1`
- 三个 duplicate keys、malformed topology、readonly、wrong owner 均原子失败；profile
  suite 18/18
- digest `a2c228178be89985`；assembly 4,078,543 B；ELF 1,300,352 B；IDL 4,727 B
- Surfpool 1.5.0 用 1,285 个 Loader write + deploy + authority transactions 完成本地部署，
  并核对 exact 1,300,397-byte ProgramData；不用 `solana-test-validator`
- 全量 194-job Lean、50 个 SVM build、Mollusk 216/216 与 Anvil 12/12 回归通过

## non-goals

- 不实现第五个/一般 key insertion、free-list reuse、delete fixup 或 runtime capacity
- 不开放 persistent raw pointer、heap `Map`、detached node 或账户外 tree ownership
- 不声明公网部署、runtime remaining accounts、Token-2022 extension 或完整 Phoenix-v1 ABI
