# R1-030 — Shared full-precision UInt64 ceiling multiply/divide

Date: 2026-08-31
Status: done

## Goal

Add allocation-free ceiling `(left * right) / denominator` without duplicating R1-029's exact
product or division algorithm, while keeping explicit caller-owned zero and overflow policy.

## Delivered contract

- `Core.Math.UInt64.mulDivCeil` and floor `mulDiv` call one private rounding kernel. Four safe
  32-bit partial products form the exact 128-bit numerator and one fixed 64-step restoring loop
  computes the floor quotient and its remainder in scalar locals.
- Ceiling increments only for a nonzero remainder. The increment is checked independently, so a
  floor quotient of `UInt64.max` with a remainder returns the caller's overflow error rather than
  wrapping to zero. Zero denominator and a floor quotient wider than UInt64 retain R1-029 policy.
- SVM `BatchSizer.prorateUp` applies covering capacity policy; EVM `EvmPriceBand.weightedUp`
  independently applies upward quote policy. Neither consumer owns or copies the division frame.

## Boundary

This slice remains unsigned UInt64 policy. Signed math, fixed-point wrappers, UInt128/UInt256
roots and saturation, and wider returned quotients remain fail closed. No target Runtime/Ops/IR/
CFG/Component/Emit case, allocation, pointer, or shared physical layout was added.
