# l4-023 systemAllocateWithSeed

## objective

`systemAllocateWithSeed` 是普通 Lean 包装，抽出成已有 `invoke`。

- 外层 0 base s+w（prelude）、1 派生账户 w、2 System
  内层 metas：派生账户 w / base s
  data `u32le(9) || accKey 0 || u64le(5) || ascii "vault" || u64le space || programId`
  （bincode AllocateWithSeed；本切片种子钉死 `"vault"`，space 编译期常量 16）
- 派生地址 = `create_with_seed(base, "vault", program_id)`
- 负例：缺 base signer → Custom(1)；错派生地址 → System Custom(5)
- 不改 SysAlloc 账户表；新例子 SysSeed
- 不再复制发射器
