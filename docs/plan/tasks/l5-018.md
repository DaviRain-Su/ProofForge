# l5-018 bounded Phoenix account-resident topology-word writes

## objective

为 Phoenix v1 固定形状账户增加第一段持久化 node-write 基础：按编译期固定的
account/base/stride/capacity 和运行时有界 slot，直接修改账户内两个 topology words；
不把 transient SVM heap、Map 或 pointer 当作持久 allocator。

## invariants

- `accDataWordSetAt` 只写外部账户；账户、base word、stride、capacity 均在抽取期固定，
  运行时只选择零基 slot 和提供 u64 value
- 每次 store 前检查账户存在、writable、owner 等于当前 program、`slot < capacity`，以及
  最终 byte range 位于 `data_len` 内；任一失败以 `Custom(1)` 退出
- 写入是显式 target effect 和 CFG CSE barrier；连续 ignored effects 保持源码顺序，
  不能被当成纯值消除或重排
- invocation 失败由 SVM 原子回滚；第二个 topology word 越界时，第一个 word 的 store
  不得泄漏到持久账户
- 账户中只保存 Phoenix/Sokoban slot index 和 packed topology words；不保存 heap pointer，
  不复制节点到动态容器
