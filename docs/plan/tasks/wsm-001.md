# wsm-001 WASM 第三 profile：XRPL Bedrock 方言 v0 竖切

## objective

按 [research/06-wasm-feasibility.md](../../research/06-wasm-feasibility.md) 路线 B
（第三个 profile）落第一刀，绑定 WASM 家族第一条链 XRPL Bedrock（XLS-0101）。
WASM 是链家族不是 target：`ProofForge/Wasm/Family.lean` 只共享外来叶子拒绝约定，
`Wasm/Xrpl/` 拥有链方言，CLI 只接受 `--target xrpl`：
`Core.Target.Registration` 拒绝 svm/evm 叶；v0 子集 fail closed（UInt64 槽、
scalar UInt64 参数、checked 五则、ite、exit ops；loop / local / vector / map /
named error / 位运算全拒）；artifact 是 scaffold-xrp 方言 Rust 源
（`xrpl_wasm_std` `get_data` / `set_data`、`#[unsafe(no_mangle)] pub extern "C"`），
zero-tool，`deployable=false`。digest 域 `xrpl-bedrock|`，与 SVM / EVM 故意不同。
XRPL 事实（crate git rev、wasm32-unknown-unknown、AlphaNet≠主网、无 rustc Tool
Lock）来自旧仓 proof_forge 的 ADR-0049/0050 研究。

mutating entry 返回 `i32` 状态码（错误码钉死：1 overflow/underflow、2
divide-by-zero），源声明的 public 返回值省略（读 view）；view 返回 `-> u64`
（FFI-safe 标量，多值 fail closed）。
