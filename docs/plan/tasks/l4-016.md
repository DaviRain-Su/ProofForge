# l4-016 createPda

## objective

`createPda lamports` 是普通 Lean 包装，抽出成已有 `invokeSigned`。

- 外层：账户 0 payer s+w、1 PDA w、2 System
- 内层 metas：payer s+w、PDA s+w（PDA 由 seeds 签字）
- 内层 data：与 `systemCreate` 相同，`u32le(0) || lamports || space=16 || programId`（52B）
- seeds：ASCII `"vault"` + `findPda "vault"`
- 负例：错 bump（`createPdaBad`，bump 钉死 0）必须失败
- 不再复制发射器
