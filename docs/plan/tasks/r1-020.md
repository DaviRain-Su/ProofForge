# R1-020 — Shared tagged return frame

## Goal

Give top-level `Option` and payload-enum results a fixed, allocation-free source frame that both
targets can bind independently, without choosing Borsh or ABI tag geometry in Extract and without
adding tagged-value operations to Core IR or either main emitter.

## Delivered

- Extract projects direct `Option<T>` results to `slot_tag, slot_p0` when `T` fits one scalar limb.
- Extract projects direct payload-enum results to `variant_tag, variant_p0, ...`, sized by the
  largest constructor. The initial enum contract accepts unit constructors and UInt64 payloads.
- Return counts now reflect the fixed source frame before target lowering. The projection names
  deliberately match the existing input-side logical frame, while canonical tag widths,
  active-payload rules, and wire bytes remain target-owned.

## Boundaries

This slice does not encode returndata. Constructed tagged results, richer Option payloads, and enum
fields other than UInt64 remain fail closed until extraction can prove their fixed frame. No heap,
pointer, account/storage geometry, Runtime effect, target Op, or Emit recipe was added.

## Verification

`Tests.CoreCodecSpec` checks direct Option and three-variant enum echoes, including exact logical
schemas, fixed frame sizes, and source projection names.

## Next

SVM should bind this frame to canonical branch-dependent Borsh output, then EVM should bind the same
logical frame to an independently defined Tagged Tuple returndata policy.
