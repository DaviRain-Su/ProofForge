# evm-004 Anvil：constructor / increment / get / overflow

## objective

对标 Mollusk Counter 四条，以及 PF `smoke_evm.sh` 的 StateCell 矩阵。

本机 `anvil` + `cast` 存在时：

1. constructor(`uint64`) 写 slot 0；`get()` 与 `cast storage 0` 一致
2. `eth_call increment` 返回新值，不提交
3. `send increment` 写回；view + storage 双读
4. `max + 1` revert，slot 0 保持
5. 带 value 的 constructor / increment 必须失败（nonpayable）

缺 anvil/cast：exit 0，打印 skip，不当绿。

## path

`runtime-tests/evm/anvil_counter.sh`, `docs/modules/evm.md`, `README.md`

## verification

- 本机有 Foundry 时脚本 exit 0，四条断言过
- overflow 后 `get()` 仍是 `2^64-1`
- `eth_call increment` 不改 storage
