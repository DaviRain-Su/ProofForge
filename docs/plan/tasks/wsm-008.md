# wsm-008 XRPL-SDK：`pf_inline` 转到 Runtime

## objective

见 [xrpl-runtime.md](../analysis/xrpl-runtime.md) XRPL-SDK。学 EVM `Sdk.Context.caller`
的分层，不学物理模型。

`ProofForge.Wasm.Xrpl.Sdk` 只提供 `@[pf_inline]` 名：

- `Context.caller` / `self` → `xrplCaller20` / `xrplSelf20`
- `Context.callerLo` / `selfLo` → `xrplCallerW0` / `xrplSelfW0`（截断视图，不是身份）
- `Context.ledgerSqn` / `parentTime` → 已有 Runtime 叶
- `Hash.sha512HalfLit` → `xrplSha512HalfLit`

Ownable 仍是源码嵌套 `if` 三叶，不是新 Op / host。`Examples.Xrpl.XrplOwn` 改走 SDK 名，
digest 不变（inline 后 IR 相同）。不新增 host import。

## 不做什么

- 不引入 Map / event / transfer / SDK Ownable façade 类型
- 不把 8 字节 `callerLo` 当权限目标
- 不把 `AccountId` 换成 `Evm.Runtime.Addr20`
