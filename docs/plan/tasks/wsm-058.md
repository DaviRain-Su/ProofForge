# wsm-058 SDK `Card` 组合层

## objective

Reusable caller-card names over existing Runtime leaves. No new host,
Op, or JSON key. Contracts write `Card.restoreCaller` / `Card.unlocked`
instead of repeating limb peeks.

digest `3b84bf36c5c309d7` (`Examples.XrplCard`).

| SDK | unfolds to |
|---|---|
| `Card.peekBal w0 w1 w2` | `peekOwnerLimbs` |
| `Card.select w0 w1 w2` | `storeOwnerLimbs` |
| `Card.restoreCaller` | `storeOwnerLimbs caller*` |
| `Card.unlocked w0 w1 w2` | `peekLockLimbs = 0` |
| `Card.callerUnlocked` | caller lock = 0 |

## 不做什么

- 不开 `Sdk.Map` / `Sdk.Payments`
- 不发明任意 JSON key Runtime 叶（会改 wasm v0 ext arity）
