# R1-009 — Bind SVM bounded Borsh vectors

## Goal

Give ordinary Lean source a bounded variable-length input carrier while preserving Solana's
resource model. The source type must have a compile-time capacity, SVM must consume canonical Borsh
`Vec<T>` bytes with an exact cursor, and the generated program must not retain a collection header,
backing pointer, heap allocation, or persistent `Map`/`Array`.

This slice covers **raw SVM input only**. Bounded returns and EVM dynamic ABI tails remain fail
closed until their target-specific policies are defined.

## Source and lowering contract

`Core.Value.BoundedVec α capacity` contains a runtime `UInt32` length and a host `Vector α
capacity`. The `Vector` is a compile-time/source carrier, not the target representation. Extract
requires a literal capacity and derives `.boundedArray capacity element`; it then resolves
`length` and fixed `values_i` projections exactly like other compiler-owned boundary projections.
Ordinary unbounded Lean `Array` remains rejected.

SVM independently selects this physical input plan:

```text
canonical Borsh wire                fixed invocation-local frame
u32 length                          u32 length local
length × encoded element     ───▶   capacity × fixed element locals
exact end cursor                     unused element locals = 0
```

The recursive `BorshDecode.boundedArray` plan owns the length local, fixed element ranges, nested
element decode plans, and the exact `4 .. 4 + capacity × element.maxBytes` resource envelope. The
generic plan interpreter checks `length ≤ capacity`, zeroes every element range, conditionally
decodes exactly `length` elements, and leaves the existing final-cursor guard to reject truncation
and trailing bytes.

This does not add an array Ops case, Component recipe, or type-specific main-emitter branch. The
only Emit change is another case in the reusable target-owned Borsh plan interpreter. No value from
the frame is an account pointer, and this wire carrier does not provide persistent storage.

## Coverage

`Examples.RawEntry.boundedValues` accepts `BoundedVec UInt64 4` and reads both the runtime length
and fixed source projections. Lean guards cover literal/dynamic-capacity profile behavior, source
schema derivation, physical local widths, min/max bytes, plan identity, CFG projection, and generic
assembly rendering. Mollusk covers lengths 0, 2, and 4 plus over-capacity, truncated header,
truncated element, and trailing-element encodings.

EVM continues to reject `.boundedArray` in `Evm.Codec` and ABI JSON generation rather than copying
the Borsh layout or guessing a dynamic offset policy.
