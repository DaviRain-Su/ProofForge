# R1-036 — Shared bounded byte and string first-match position

Date: 2026-09-01
Status: done

## Goal

Give both targets a reusable allocation-free first-substring-position policy comparable to Rust
slice search and Solidity bytes/string helpers, returning a typed optional byte position without
adding a search opcode, container, allocator, pointer, or target-specific source API.

## Delivered contract

- `BoundedBytes.findIndex?` accepts independently sized haystack and needle carriers. Both frames
  must be canonical; an empty needle returns `some 0`, the first overlapping match wins, and an
  absent, longer, or malformed needle returns `none`. Inactive fixed-frame tails are ignored.
- Contains, prefix, suffix, and first-position policy share one private static product-scan kernel.
  Its position+1 scalar is a lowering detail only; the public API exposes `Option UInt64`, not a
  sentinel or runtime-selected geometry.
- `BoundedString.findIndex?` reuses the compiler-erased byte view and reports a UTF-8 byte offset.
  String validity remains a checked-constructor/target-codec invariant; this operation does not
  add normalization, collation, or Unicode-scalar indexing.
- Extract sequences an effect-free bounded scalar-loop result through the existing join-local
  contract before caller comparison. Constructed one-limb Options must then reach every successful
  CFG exit as exactly two explicit leaves; failures remain frame-free and missing values are never
  guessed from adjacent locals.
- SVM `RawEntry` tags 37/38 bind canonical Borsh Option output. The independent
  `Examples.EvmFindIndex` consumer binds canonical adjacent dynamic tails to ABI
  `(bool,uint64)` output. Core remains the sole search-policy owner.
- Generated EVM runtime code declares the emitter's existing fixed 4096-byte low-memory scratch
  window with `mstore(64, memoryguard(4096))`. This lets solc 0.8.34 spill bounded-loop stack values
  without introducing a source heap. The bound is derived as two maximum 64-word target-local ABI
  frames, covering codec output headers/staging and the bounded source frame.

## Boundary

This is exact bounded first-substring byte position, not split/replace/regex, concatenation,
normalization/collation, Unicode-scalar indexing, allocation, persistence, or a shared wire layout.
No Runtime, Ops, IR, CFG, or Component case was added; Extract and EVM Emit received only generic
frame/resource corrections shared by future bounded-loop and ABI consumers.
