# l4-032 sol_keccak256 / keccak256Lit

## objective

`keccak256Lit` 是 `sha256Lit` 的兄弟叶子，不是 CPI。

- Lean：`keccak256Lit (seed : String) : UInt64` — 编译期 ASCII；返回 Keccak-256 digest 第一个小端 u64
- 抽出按名字认；发射 `sol_keccak256`，一条 `SolBytes`，`r2 = 1`
- 发射器与 `sha256Lit` 共用同一条 scratch / SolBytes 路径，只换 syscall 名
- 完整 32B / 多切片 / blake3 / poseidon 仍 FC
- 新例子 Keccak，不折进 Hash
- Hash digest 仍是 `2fb59b956afdf97f`；Keys digest 仍是 `b91c2a143e8ff667`

官方 C ABI 与 `sol_sha256` 同形（Ethereum Keccak，不是 FIPS SHA3-256）。

## verification

- Keccak Mollusk：`keccak("vault")` / `"ok"` / `""` 首 u64 与宿主 `sha3::Keccak256` 一致
- Hash / Keys digest 不回退

- Keccak digest `9c6001a9b0534a0a`；非 CPI、非 walk
- Mollusk：`vault` / `ok` / `""` 首 u64 与宿主 `sha3::Keccak256` 一致；空串与 sha256 不同
- Hash digest 仍是 `2fb59b956afdf97f`；Keys digest 仍是 `b91c2a143e8ff667`
