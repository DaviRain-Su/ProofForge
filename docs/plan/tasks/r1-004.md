# R1-004 — Derive bounded aggregate source schemas

## Goal

Recover logical contract-boundary shapes from ordinary Lean types before either target chooses a
wire or storage layout. This slice must distinguish scalar values from tuples, records, enums,
options, and literal-length vectors without adding aggregate Ops, emitter cases, or a fake shared
physical ABI.

This is the **aggregate source-metadata slice**. SVM aggregate Borsh binding and EVM aggregate ABI
binding remain separate target-adapter work.

## Delivered

- Extract derives validated `Core.Codec.Schema` values for Bool/fixed scalars, Unit, `Prod`,
  non-polymorphic user records, bounded non-recursive enums, `Option`, and literal-length `Vector`.
  Record field names and enum variant payload shapes are retained.
- `Core.IR.Method` now carries one `paramSchemas` entry per public parameter and a logical `retSchema`.
  Mutating methods expose only the result in `Except Error (State × Result)`; persisted State and
  the effect wrapper do not leak into the public result schema.
- Core target projection validates and preserves the schema metadata. SVM and EVM IR preserve it
  too, while explicitly rejecting aggregate parameters until their independent physical adapters
  exist. Aggregate values therefore cannot fall through the legacy width path as `uint64`.
- Scalar compatibility metadata is all-or-nothing. A method whose parameters are all scalar keeps
  `paramTypes`/`paramWidths`; a method containing an aggregate leaves those legacy arrays empty.
  Existing bounded scalar-product returns remain available, but their source tuple shape is no
  longer erased.
- Profile treats a literal `Vector α n` length as compile-time schema metadata, like literal valid
  `FixedBytes n`, while runtime or polymorphic `Nat` remains forbidden.
- Dynamic `Array`, recursive types, inherited records, polymorphic records, nonliteral lengths,
  malformed descriptors, and resource-budget overflow fail in Profile/Extract/Core projection,
  before target emission.

The ownership path is:

```text
ordinary Lean boundary type
            │
            ▼
Extract.codecSchemaOfType
            │ validated logical shape only
            ▼
 Core.IR.Method paramSchemas / retSchema
            │
     ┌──────┴──────┐
     ▼             ▼
 SVM IR         EVM IR
 Borsh pending  ABI pending
```

No Ops, component payload, SVM Emit, or EVM Emit variant was added in this slice.

## Verification

- Focused schema/profile/target/build guards pass, including both target registries' Lean build
  specifications.
- The aggregate fixture covers nested tuple/option, named record fields, enum payloads,
  literal-length vectors, Unit, and scalar-product return metadata.
- Negative guards cover dynamic arrays, recursion, inheritance, polymorphism, and the 4,096-element
  schema budget.
- Existing SVM and EVM canonical digests and emitted artifacts remain unchanged; this slice adds
  metadata and fail-closed target gates only.
