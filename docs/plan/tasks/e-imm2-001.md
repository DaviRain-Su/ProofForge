# e-imm2-001 第二套同型构造期 immutable

## objective

同一合约可以烘焙两个 `uint64` 和两个 `Addr20`。名字仍编译期固定：`imm0`/`imm1`、`immAddr`/`immAddr2`。不是通用 immutable 表。

- `evmImmU64b` → `loadimmutable("imm1")`
- `evmImm20b` → `loadimmutable("immAddr2")` 再拆三叶
- ctor 按参数顺序烘焙：第一个窄整数 `imm0`，第二个 `imm1`；第一个 address `immAddr`，第二个 `immAddr2`
- `Examples.Evm.Const.init (seed salt : UInt64) (who peer : Addr20)`
- `seedOf`/`saltOf`/`whoOf`/`peerOf`
- Anvil：四个 immutable 部署后可读；`touch` dummy 不影响它们
- SVM / Legacy adapter 拒新叶

## 不做

动态 immutable 名字；超过两套同型；把 Ownable/Token 改成多 immutable。
