# e-u256-001 显式 UInt256 + checked 四字算术

## objective

E-U256 第一包。默认算术仍是 `UInt64`。新增 `ProofForge.Evm.Runtime.UInt256`：四个 `UInt64` 叶，ABI 一个 `uint256`。

- `structure UInt256 where w0 w1 w2 w3 : UInt64`（w0 最低）
- 封闭 `evmAdd256` / `evmSub256` / `evmMul256`；溢出 `revert(0,0)`
- 抽出：参数 `paramWidths = 32`；返回 `retWidths = #[32]`、`retCount = 4`
- Yul：calldata 一个 word；`.field arg "w0..w3"` 按 64-bit little-endian 拆叶；返回四叶 pack 回 `uint256`
- `Examples.Wide` + Anvil：跨 64-bit 边界加减乘、溢出保持
- SVM 拒 `arith256`

## 不做

把 Token / Vault 余额改成 `UInt256`（下一刀）；除法 / 取模；有符号 `Int256`；默认把所有 `UInt64` 升宽。
