# R4-001 — EVM-RT-2a typed closed-call result contract

## Goal

Stop spelling CALL/STATICCALL success and returndata gates independently at every EVM closed-call
site. Give target emitters one typed, bounded result policy without exposing arbitrary callee,
delegatecall, create, unbounded returndata, or hidden memory allocation to source contracts.

This is the result-policy foundation of EVM-RT-2. Typed LOG/custom-error expansion remains a
separate slice.

## Delivered contract

`Evm.CallResult` names three established policies:

- `nonzeroWordOrEmpty`: CALL succeeds and returndata is empty or exactly one nonzero word;
- `exactWord`: CALL/STATICCALL succeeds and returns exactly one 32-byte word to the emitter;
- `ignored`: the call succeeds and copies no returndata.

`Request` binds call kind, closed-call input size, result policy, and whether the CALL carries value.
`CallResult.Emit` is the only interpreter for the matching Yul call, success gate, return-size gate,
and optional returned word. A STATICCALL carrying value, or a request/value-expression mismatch,
fails before Yul is emitted.

`ClosedCall.Emit` now uses the interpreter for ERC-20 transfer/approve/transferFrom, token permit,
balance/allowance reads, WETH deposit/withdraw, and closed router swaps. Existing target component
and IR identity is unchanged.

## Compatibility and resource boundary

- At most 32 returndata bytes are copied to memory offset zero; success-only calls copy zero bytes.
- The ERC-20 compatibility policy deliberately preserves the previous **nonzero** word rule. It
  does not silently tighten legacy token compatibility by requiring the canonical ABI Bool value
  to be exactly one.
- Wrong return length, zero return word, call failure, malformed value shape, and missing exact
  word fail closed with the existing revert/extraction behavior.
- Callee and calldata construction remain owned by the closed `Evm.ClosedCall` vocabulary. This
  result interpreter is not a source API for arbitrary calls.

## Evidence

- Focused call-result and consumer regression: 113 Lean jobs.
- Full aggregate regression: 269 Lean jobs; Anvil 20/20.
- Vault/Token Yul, bytecode, and ABI artifacts are byte-identical to the pre-refactor baseline.
- All 20 registered EVM contracts compile with solc 0.8.34.
- Ownership and whitespace gates pass.

## Remaining EVM-RT-2 work

- typed LOG0..4 plans and reusable custom-error data plans;
- explicit payable/receive policy consolidation where current native effects still duplicate shape;
- precompile-specific return contracts remain closed and separate from arbitrary external calls.
