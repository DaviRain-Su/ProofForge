# R1-011 — Cross-target codec plan conformance

## Goal

Close R1's shared protocol-value phase with one target-neutral conformance fixture. The fixture must
prove that SVM Borsh and EVM ABI plans preserve the same logical source projections without
pretending that byte widths, tags, offsets, padding, or storage geometry are shared.

## Delivered

- `Tests.CrossTargetCodecSpec` feeds the same static record, tagged option, and bounded record-array
  schemas to `Svm.EntryAdapter.borshPlan` and `Evm.Codec.inputPlan`.
- Every pair retains identical source projection names and fixed logical frame order.
- Static inputs demonstrate independent Borsh byte widths versus ABI words.
- Tagged inputs demonstrate SVM's variable Borsh payload length versus EVM Tagged Tuple v1's fixed
  inactive-zero guard.
- Bounded inputs demonstrate SVM's `u32 length + active prefix` versus EVM's canonical dynamic tail,
  while both keep the same compile-time-capacity scalar frame.

The fixture contains no shared wire encoder, account offset, storage slot, heap collection, pointer,
or target operation. Target-specific malformed-byte matrices remain in RawEntry/Mollusk and
EvmBounded/Anvil rather than being weakened into one artificial cross-target format.

## Verification

- `lake build Tests.CrossTargetCodecSpec` passes all guards.
- `lake build Tests` passes the aggregate Lean gate.
- Ownership and whitespace checks pass.
- This test-only slice changes no generated SVM or EVM artifact, so runtime deployment suites are
  not repeated.
