# l5-007 Phoenix bounded N=4 bid lifecycle

## objective

在 ask-side 规范之上补齐对称的四档 bid book：官方 encoded sequence、free-funds
quote collateral、满书驱逐、按 ID reduce/cancel、sell IOC、TIF、费用和三种
self-trade 行为。

## path

`Projects/Phoenix.lean`, `Tests/PhoenixSpec.lean`, `ProofForge/Svm/Emit.lean`

## verification

- bid 按价格降序、同价 encoded sequence 降序（时间 FIFO）
- quote collateral 按 `floor(tick * price * size / baseLotsPerBaseUnit)` 锁定和解锁
- 满书只由严格更高价驱逐最差 bid
- sell IOC 跨档、部分成交、slot/time TIF 和 fee 记账正确
- Abort / CancelProvide / DecrementTake 的宿主和链上结果一致
- 真实源可生成 eBPF ELF，assembly 无重复 label

## 非目标

动态 Sokoban allocator/旋转、按 trader 分立的余额树、u128 client id、seat/vault
完整生命周期和 event batch 仍是独立 refinement / account-model 切片。
