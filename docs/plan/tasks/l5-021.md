# l5-021 exact third Phoenix trader registration

## objective

按 Sokoban 0.3.0 的账户内 bump allocator 与 red-black insertion，把最小 128-seat trader
tree 从 canonical 两节点推进到三个 distinct keys。覆盖 LL/LR/RR/RL rotation/recolor 和
两个无需 fix-up 的 key placements；全程只写固定账户 slot index，不构造 heap tree/Map。

## invariants

- 输入必须是 84,944-byte `(512,512,128)` shape，trader header 为
  `root=1,padding=0,size=2,bump=3,free=3`；address 2 必须是 address 1 的唯一 red child，
  parent reciprocity、颜色和两把 existing keys 的 raw-byte order 都必须 canonical
- 新 key 必须与 address 1/2 都 distinct；四个 little-endian u64 limbs 通过通用
  `svmByteSwap64` 按原始 32-byte Pubkey 顺序比较，目标只发射 sBPF `be64`
- bump allocation 固定返回 address 3，并原子发布 `size=3,bump=4,free=4`；slot 3 的
  18 words 全部覆盖，既有两个 TraderState 不因 rotation 被复制或清零
- 六种最终 topology 必须与 Sokoban `_insert` / `_fix_insert` / `_rotate_dir` 一致：
  LL/LR/RR/RL 后 root 为 address 2 或 3，两个 no-fix 分支保留 root address 1
- 成功路径精确保留 25 个 external-account writes；无法解码任一 write operand 时整个
  extraction fail closed，不能把该 effect 当作可忽略的纯 let
- duplicate/malformed 以 `Custom(0x1001)` fail closed；readonly/wrong owner store 以
  `Custom(1)` 失败；所有失败保持完整账户 bytes 不变

## verification

- Lean guards 钉住六组 topology selector、通用 byte-swap value arity，以及成功分支精确
  25 writes；负向 extractor fixture 证明 dynamic account operand 不会导致 write 静默消失
- Mollusk 从 first + second entry points 构造六种 canonical input，slot 3 预填 stale bytes，
  对完整 84,944-byte output 做 byte-for-byte 比较；existing TraderState 保留，且每种结果
  都满足 `bodyEntryCount=3` 与 `traderTreeValid=1`
- 两个 duplicate keys、malformed topology、readonly、wrong owner 均原子失败；profile
  suite 16/16
- digest `d9b9ee673526ff9f`；assembly 3,949,948 B；ELF 1,261,744 B；IDL 4,392 B
- Surfpool 1.5.0 用 1,247 个 Loader write + deploy + authority transactions 完成本地部署，
  并核对 exact 1,261,789-byte ProgramData；不用 `solana-test-validator`
- 全量 194-job Lean、50 个 SVM build、Mollusk 214/214 与 Anvil 12/12 回归通过

## non-goals

- 不实现第四个/一般 key insertion、free-list reuse、delete fixup 或 runtime capacity
- 不开放 persistent raw pointer、heap `Map`、detached node 或账户外 tree ownership
- 不声明公网部署、runtime remaining accounts、Token-2022 extension 或完整 Phoenix-v1 ABI
