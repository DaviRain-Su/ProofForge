# l1-003 Program 内容寻址 digest

## objective

`IR.digestHex` 是 kernel 可算的内容寻址身份。规范化文本只含 `name`、`fields`、每个方法的 `kind` / `ixName` / `paramCount` / `ops`。不含 Lean 全名、不含 sketch。方法按 `ixName` 排序后再哈希。算法是 FNV-1a 64，十六进制。Lean 4.31 无内建 SHA-256；digest 必须能进 `#guard` / `theorem`，不能走 IO。

抽出的 Program 与发射器用的 Program 必须同一 digest。改一个 op 必变。`.s` 头注释写入 digest。

## path

`SolanaLean/IR.lean`, `Commands.lean`, `Emit.lean`, `Tests/BuildSpec.lean`, `docs/modules/ir.md`

## verification

- 同一 Program 两次 `digestHex` 相等
- 改一个 op 后 digest 不同
- `#solana_build` 打印 digest
- 发射文本含 `digest=`
