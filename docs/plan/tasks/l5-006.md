# l5-006 Sokoban 节点 + 定长 Vector

## objective

官方红黑树节点摊成 `Vector Node n`。`Node` 是用户 structure，物理顺序跟 Sokoban 一致：left / right / parent / color / key / value。`SENTINEL = 0`，地址 1-based。

除布局和 `nodes[0].value` 外，本切片随后补齐动态叶读写、两节点 insert smoke、
左旋，以及 Sokoban 对齐的 N=4 bump/free-list allocator。allocator 使用一过尾标记 5，
release 后按 LIFO 地址复用。

## path
