# sf-009 OrderedMap find/insert/remove 模型

## 目标

把 OrderedMap 从「委托 Source 的定义等式」推进到 AccountWords 上的有界代数。

## 交付（可拆 PR）

1. find：缺失 → 0；命中 → slot；不改内存
2. insert：新键分配+链接；已存在更新 payload；满 fail-closed
3. remove：删后 find 为 0；size 守恒叙述与 Tree 片对齐
4. 明确信任边界：旋转/颜色细节可引用 Examples/Tree 引理，或本片只证「索引层」而把结构保持交给 sf-011

## 验收

SF-5b → done（若拆分，在矩阵注明子状态）。
