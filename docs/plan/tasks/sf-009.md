# sf-009 OrderedMap find/insert/remove 模型

## 目标

把 OrderedMap 从「委托 Source 的定义等式」推进到 AccountWords 上的有界代数。

## 交付

1. AccountWords facade：`mSlotValue` / `mFindValueKey4`（缺失 → 0；命中 → 读 payload）
2. 形状 fail-closed：`key4`/`fifo` 错形 find/insert/remove = 0
3. `mOrderedMapInitialize` 头字清零 + allocator cursor 复位
4. 索引层 `AssocIndex` find/insert/remove/满失败/size 守恒（RB 链接/旋转/染色 → **sf-011**）

## 信任边界

`accDataRbTree*` 宿主桩不在本片 refinement；assoc-list 是 L2 索引合同，树结构保持交给 sf-011。

## 验收
