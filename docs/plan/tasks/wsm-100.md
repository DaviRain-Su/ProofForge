# wsm-100 探针 Trust line 读取路径（不是 Sdk.Trustline）

## objective

`trustline_id` import **已经在**（wsm-036：零账户 → -16 `INVALID_ACCOUNT`）。
本刀走完和 AccountRoot.Balance 相同的路径，**不开 Runtime / SDK 名**：

1. `tx_field(sfAccount)` → caller 20B
2. 编译期 issuer 20B + ISO `USD` 20B currency
3. `trustline_id` → 32B index
4. `cache_le` → slot
5. `le_field(Balance=393218)` → STAmount 48B

没有 RippleState 时，负 host 码也算「路径跑了」。不要把缺 line 当成失败。
有真实 IOU 再解码 mantissa 是下一刀（那时才开 Runtime 叶）。

组合层（pause/freeze/take/claw/cash）到 wsm-099 **收口**。不再加同形 Example。
