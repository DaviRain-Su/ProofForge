# l2-001 带类型的字段表 + Option 双叶

## objective

`Program.slots` 取代「全是 UInt64 槽」。每个槽有名字、字节宽、ABI 后缀。偏移按声明顺序累加，从 header 后 8 起。`UInt8/16/32/64` 各占 1/2/4/8 字节。`Option UInt64` 展开成 `name_tag` + `name_p0` 两叶（各 8 字节，对齐 PF OptionState）。其它类型 fail closed。

`Examples.Flag`：`flag : UInt8` + `count : UInt64`。`Examples.Maybe`：`slot : Option UInt64`。layout marker 手工登记。未登记布局 fail closed。

load/store 按宽度用 `ldxb`/`ldxh`/`ldxw`/`ldxdw`。`Option.none` 清零两叶；`some n` 写 tag=1、payload=n。view `isSome` 返回 tag。

## path

`SolanaLean/IR.lean`, `Extract.lean`, `Emit.lean`, `Examples/Flag.lean`, `Examples/Maybe.lean`, `Tests/*`, `runtime-tests/solana/tests/{flag,maybe}.rs`

## verification

- Flag 字段偏移：flag=8 宽 1，count=9 宽 8；data_len 对齐到 8
- Maybe 槽：slot_tag=8、slot_p0=16；data_len 24
- 非 UInt / 嵌套 Option fail closed
- Counter / Pair Mollusk 不回退
- Flag / Maybe 各有 Mollusk：init、写窄字段、none 清零、some 写回
