# R1-028 — Shared UInt64 ceiling logarithms and square root

Date: 2026-08-31
Status: done

## Goal

Add explicit allocation-free upward rounding for the shared UInt64 logarithm and square-root
families, matching OpenZeppelin's unsigned ceiling policy without adding target instructions,
power tables, floating point, or wide temporary values.

## Delivered contract

- `Core.Math.UInt64.log2Ceil`, `log10Ceil`, and `log256Ceil` return the least exponent whose base
  power covers the input; zero and one map to zero. `sqrtCeil` returns the least root whose square
  covers the input, including `2^32` at `UInt64.max`.
- Every helper uses the exact identity `ceil(f(input)) = floor(f(input - 1)) + 1` on its positive
  domain. Zero is guarded before predecessor formation, so no subtraction underflow, power, or
  square is needed. The logarithms retain fixed 6/5/7-step ladders; square root retains the
  five-step seed and six-step two-scalar Newton frame.
- SVM `BatchSizer` exposes covering orders and a covering grid root. EVM `EvmPriceBand` exposes
  upward quote bands and normalization root. They share value policy only, not state, ABI/account
  geometry, errors, or physical layout.

## Boundary

This slice is UInt64-only. Signed logarithms, UInt128/UInt256 roots, full-precision multiply/divide,
nth roots, and fixed-point roots remain fail closed. No helper silently changes checked arithmetic
or introduces a persistent/transient allocator.
