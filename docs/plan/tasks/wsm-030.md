# wsm-030 探针：合约发 Payment（Transia emit，不是 `submitTransaction`）

## objective

XLS-0101 §20 叙事里的 `submitTransaction({Payment…})` **不是** WASM import 名。
escrow stdlib（`ripple/xrpl-wasm-stdlib`）只有 `set_data`，没有发交易。
AlphaNet 智能合约（`dangell/smart-contracts` / `Transia-RnD/xrpl-wasm-std`）注册的是：

| import | 签名 | 用途 |
|---|---|---|
| `host_lib.build_txn` | `(i32 tt) → i32` | Payment = 0；返回 builder index |
| `host_lib.add_txn_field` | `(i32 idx, i32 sfield, ptr, len) → i32` | Amount=393217，Destination=524291 |
| `host_lib.emit_built_txn` | `(i32 idx) → i32` | 合约伪账户发出已构建的 STTx |
| `host_lib.emit_txn` | `(ptr, len) → i32` | 已序列化 STTx；本探针不用 |

## 活网（2026-08-29，`3.3.0-rc1` / 21337）

合约 `rLPw4AAL1QAo4nBWnH4vpemZN1E1ZbpWzB`：

| 步骤 | 结果 |
|---|---|
| `ContractCreate` 含三条 import | tesSUCCESS |
| `pokeBuild` = `build_txn(Payment=0)` | tesSUCCESS / **vmReturnCode=0**（host 存在，builder index 0） |
| 普通 Payment 打进 ContractAccount | **tecNO_PERMISSION**（伪账户，不是没钱） |
| `pokeEmit` 192 drops → caller | tecBYTECODE_REJECTED / **vmReturnCode=-196** = `tecPSEUDO_ACCOUNT` |

host **已注册且能跑**。Payment **没有落地**。资金路径不是事后 `Payment`，可能是 Create 时的 `tfSendAmount`（带参，公共 RPC 仍 502）。

**不开 Runtime 叶，不开 `Sdk.Payments` / `Sdk.Amm`。** 下一刀：能给伪账户注资的 Create 路径，或读懂 -196 是否「Account 字段被填成了合约自己」。
