# wsm-030 探针：合约发 Payment（Transia emit，不是 `submitTransaction`）

## objective

XLS-0101 §20 叙事里的 `submitTransaction({Payment…})` **不是** WASM import 名。
escrow stdlib（`ripple/xrpl-wasm-stdlib`）只有 `set_data`，没有发交易。
AlphaNet 智能合约（`dangell/smart-contracts` / `Transia-RnD/xrpl-wasm-std`）注册的是：

| import | 签名 | 用途 |
|---|---|---|
| `host_lib.build_txn` | `(i32 tt) → i32` | Payment = 0；返回 builder index |
| `host_lib.add_txn_field` | `(i32 idx, i32 sfield, ptr, len) → i32` | Amount=393217，Destination=524291 |
| `host_lib.emit_built_txn` | `(i32 idx) → i32` | 合约伪账户发出已构建的 STTx |
| `host_lib.emit_txn` | `(ptr, len) → i32` | 已序列化 STTx；本探针不用 |

|---|---|

host **已注册且能跑**。Payment **没有落地**。

续：Create `InstanceParameters`（UINT64 或 `tfSendAmount` AMOUNT）submit → **temMALFORMED**。

`tfSendAmount` 可以 Create，Call 带值仍 malformed。`BatchV1_1` 已开。
这版公共 AlphaNet **没有** 给伪账户注资的可用路径。

**不开 Runtime 叶，不开 `Sdk.Payments` / `Sdk.Amm`。**
