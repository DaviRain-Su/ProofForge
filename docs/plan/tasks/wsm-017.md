# wsm-017 XRPL-SDK-MARK：owner 门后写 SHA-512Half（XrplMark）

## objective

缺口文档「现在就能做」的 owner+hash 组合。不新 host。

- `Examples.Xrpl.XrplMark`：零参数 `initialize` 记 caller 为 owner
- `stamp` 走 `Access.requireOwner`，然后写 `Hash.sha512HalfLit "vault"`
- `renounce` 清零 owner 三叶；同一把钥匙再 `stamp` → 状态码 **3**，`hashed` 不变
- 活网 `hashed` 钉 `4898221643817197762`（与 Bedrock `hash.sh` 同一字面量）

## 不做什么

- 不改 `XrplHash` digest（Bedrock 无权限门仍用它）
- 不把 live AlphaNet 放进 CI
- 不做动态 hash 输入 / 完整 32B / keccak
