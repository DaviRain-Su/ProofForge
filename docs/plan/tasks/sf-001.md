# sf-001 Queue 非空 push 读回

## 目标

在 `mQueuePush_empty_readback` 之后，补齐 **非空** 队列 push 的模型读回。

## 交付定理（建议名）

- `mQueuePush_nonempty_no_wrap_readback`：`0 < head`、`head + size ≤ cap` 时 count/slot 读回
- `mQueuePush_nonempty_wrap_readback`：环绕分支 `tail = head + size - cap` 读回
- 如需要：把「选择哪个分支」的链接引理写成 `mQueuePush_links_*`

前置：`q.wellFormed`、未满、`head ≠ 0`（或显式 size/head 假设）。

## 手法

`mQueuePushAt_twoWrites` + 三词分离（count≠head≠slots）+ `mWriteWord_*`；对齐 empty 片。
