# l4-024 systemCreateWithSeed

## objective

`systemCreateWithSeed` 是普通 Lean 包装，抽出成已有 `invoke`。

- 外层 0 funder=base s+w（prelude）、1 派生账户 w、2 System
  内层 metas：funder s+w / 派生账户 w
  data `u32le(3) || accKey 0 || u64le(5) || ascii "vault" || u64le lamports || u64le space || programId`
  （bincode CreateAccountWithSeed；种子钉死 `"vault"`，space 编译期常量 16）
- 派生地址 = `create_with_seed(base, "vault", program_id)`
- 挂在 SysSeed 上，不另开程序；cpiAccountCount 仍是 3
- 负例：缺 base signer → Custom(1)；错派生地址 → System Custom(5)
- 不再复制发射器
