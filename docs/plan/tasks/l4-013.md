# l4-013 System assign / allocate

## objective

`systemAssign` / `systemAllocate space` 是普通 Lean 包装，抽出成已有 `invoke`。

- 外层：账户 0 s+w、System
- Assign 内层：`u32le(1) || owner32`，owner = 当前 program id
- Allocate 内层：`u32le(8) || u64le space`；space 本切片钉死 16
- 负例：缺账户 0 signer
- 不再复制发射器

## path

`Ops.lean`, `Runtime.lean`, `Extract.lean`, `Golden.lean`, `Examples/SysAlloc.lean`, `Tests/*`, `runtime-tests/solana/tests/sys_alloc.rs`

## verification

- SysAlloc Mollusk：allocate 把空 System 账户扩到 16 字节；assign 把 owner 改成当前 program
- 缺 signer → Custom(1)
- Create digest 不回退
