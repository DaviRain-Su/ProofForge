# wsm-014 AlphaNet 零参数烟测 + 本仓 deploy/call

## objective

公开 AlphaNet 是工程目标。本地 Bedrock 镜像 **不是** 同一条 ABI，不能拿来
「本地模拟 AlphaNet」。本地模拟以后要跑 `alphanet` 分支 rippled；本刀不做节点。

本仓自己提交 `ContractCreate` / `ContractCall`：

- 用节点 `sign` + `server_definitions`，不走 bedrock 默认 codec
- 公共 RPC 对带 `Parameters` 的 `ContractCall` 返回 HTTP 502，所以烟测合约
  `Examples.Xrpl.XrplSmoke` **零参数**
- AlphaNet `home_le_field(sfOwner)` 返回 `-10`；存储所有者改 `tx_field(sfAccount)`
- 缺 `ContractData` 的 `-10` 当缺字段，不当 trap
- `ContractJson` key 是槽名的大写 hex（`value` → `76616C7565`）

## 不做什么

- 不把 live AlphaNet 放进 CI
- 不把现成 Bedrock Docker 当 AlphaNet
- 不重写 bedrock CLI / Rust 工程
