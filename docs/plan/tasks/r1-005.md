# R1-005 — Bind static aggregate Borsh on SVM

## Goal

Lower the shared logical schemas from R1-004 into an SVM-owned, exact-cursor Borsh entry plan for
ordinary Lean records, products, and literal-length vectors. The binding must use fixed scalar
locals only: no heap aggregate, persistent pointer, account offset, Phoenix policy, or new
Ops/Component/main-Emit variant.

This is the **SVM static aggregate adapter slice**. EVM owns its separate canonical ABI binding;
Borsh enum/option tags, bounded-array lengths, and generated SVM aggregate entrypoints remain
explicit later work.

## Delivered

- `Core.Codec.staticLeaves` provides typed, source-order paths through unit/scalar/tuple/record/
  fixed-array schemas. These paths are logical identities only; flattened compatibility names are
  derived and ambiguous names are rejected by the target binder rather than guessed.
- `Svm.EntryAdapter.staticBorshLeaves` independently selects little-endian scalar limb widths.
  Each logical parameter maps to a statically bounded physical-local range; `Unit` consumes zero
  bytes and wide fixed values consume their existing fixed UInt64 limbs.
- Exact raw-entry decoding now enforces canonical Borsh Bool bytes (`0` or `1`), exact total input
  length, fixed local capacity, and complete aggregate return metadata. SVM address values and
  tagged/dynamic schemas still fail closed unless an existing explicit target annotation owns the
  representation.
- Extract recognizes ordinary `Prod.fst`/`Prod.snd` and literal fixed-vector projections. Public
  parameter field uses are tracked structurally and no longer mistaken for managed-State fields.
- SVM IR resolves each typed aggregate projection to its fixed decoded local before shared CFG
  lowering. Generated SVM ABI remains closed to aggregate parameters; only the existing raw-entry
  target adapter is widened in this slice.
- `Examples.RawEntry.aggregate` proves the source surface with a nested record, product, and
  `Vector UInt16 3`. Its wire contract is source-order Borsh:
  `tag || u64 || u8 || bool || u32 || u64 || 3*u16` (29 bytes).

The ownership path is:

```text
Core logical StaticLeaf path
             │
             ▼
Svm.EntryAdapter Borsh width / Bool policy
             │ fixed scalar local ranges
             ▼
        SVM CFG + Emit
```

No aggregate value is allocated. No Borsh geometry enters Core, and no application or protocol
name enters SVM Runtime/IR/Emit.
