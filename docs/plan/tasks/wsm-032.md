# wsm-032 本地 SmartContract 节点（transia/alphanet，不是 Bedrock）

## objective

公共 AlphaNet `3.3.0-rc1` / network_id **21337** 上三条表面仍被节点挡住。本刀起一台
**本地** SmartContract standalone，把那三条再打一遍。不是 Bedrock
`lejamon/rippled_smart_contract_vault_x86`，也不是把公共 21337 当成本地。

探针：`runtime-tests/xrpl/blocked.sh`（默认 RPC 本地 15005）。

这台 **不是** XLS-0102 公开名。WAMR：`Import not found: tx_field`。
host 表是旧 `get_*` ABI（`get_tx_field` / `get_current_ledger_obj_field` /
`set_data_object_field` / `build_txn` / `emit_built_txn`）。
`ContractCall` 字段是 `ComputationAllowance`，没有 `Gas`。
`alphanet-rpc.js` 按 `server_definitions` 选字段；standalone 走 `ledger_accept`。

本地探针 WAT：`probe-emit-local.wat` / `probe-owner-local.wat` /
`probe-param-local.wat`。公开 3.3.0 探针仍是 `probe-emit.wat` /
`probe-owner.wat`（`tx_field` / `home_le_field`）。

## 三条探针（2026-08-30）

| 表面 | 本地 2.6.1-rc1 / 63456 | 公共 3.3.0-rc1 / 21337 |
|---|---|---|
| `emit_built_txn` Payment | host 在。缺 NetworkID → WasmTrace **telREQUIRES_NETWORK_ID** / **-385**。小端 NetworkID → **telWRONG_NETWORK** / **-386**。大端 `0x0000F7E0` 后 open-ledger **tesSUCCESS**，关账本内层 Payment **tecUNFUNDED_PAYMENT**（合约余额 0，要 1000192 drops），然后 rippled **assert** `Transactor::reset`，docker **exit 139** | pokeBuild=0；pokeEmit **-196 tecPSEUDO_ACCOUNT** |
| 写合约账户 ContractData | `pokeCaller` **0**（caller 卡可写）。`pokeSelf` `get_current_ledger_obj_field(sfContractAccount=524315)` → host **-17 INVALID_FIELD**（没写到 -22） | caller 可写；`home_le_field(524320)` 后写 **-22** |
| ContractCall Parameters | `sign` 能编 UINT64 Parameters。`submit` → 节点 **SIGSEGV / exit 139**。默认 `blocked.sh` 不再打；`XRPL_PROBE_PARAMS=1` 可复现 | 公共 HTTP **502** |
| Create `InstanceParameters` tfSendAmount | `sign` 拒：`InstanceParameter contents did not meet requirements` | **temMALFORMED** |

`Sdk.Payments` / `Sdk.Map` **仍关**。emit 在这台节点上过了 NetworkID 预检，
但伪账户没钱，关账本 assert，**Payment 没有落地**。

## 不做什么

- 不把 `transia/alphanet` 当成公开 AlphaNet 模拟器
- 不把 Bedrock vault 镜像当 AlphaNet
- 不把本地 `get_*` 名写进 `--target xrpl-alphanet`
- 不开 `Sdk.Payments` / `Sdk.Map`
- 不把 docker 崩溃当 tesSUCCESS
