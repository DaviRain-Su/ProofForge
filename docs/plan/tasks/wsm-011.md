# wsm-011 XRPL-RT-2：parent hash + base fee

## objective

见 [xrpl-sdk-gap.md](../analysis/xrpl-sdk-gap.md) RT-2。本镜像已有
`host_lib.get_parent_ledger_hash`、`host_lib.get_base_fee`。

- `xrplParentHashW0`：host 写 32 字节，只取第一个小端 UInt64。完整 32B 仍 FC。
  不是 EVM `blockhash`。
- `xrplBaseFee`：本镜像与 `get_ledger_sqn` 同形 `() → i32`，零扩展到 UInt64。
  不是 EVM `baseFee` UInt256。

`Examples.Xrpl.XrplRt2`：`stamp` 把两叶写入槽。本地：两槽都 > 0（hash 随账本变，不钉死）。

## 不做什么

- 不返回完整 32B、不接 `trace_*`、不开 Vec/Map
- 不把 fee 当成 EVM 256-bit
