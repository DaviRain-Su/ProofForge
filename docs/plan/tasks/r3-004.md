# R3-004 — SVM static PDA/System facade foundation

## Goal

Move reusable PDA and System Program source names into `Svm.Sdk` so applications stop repeating
Runtime leaves and CPI instruction recipes, while preserving the existing generic invoke/IR/Emit
contracts and bounded Solana resource model.

## Delivered contract

- `Svm.Sdk.Pda.Ascii` exposes one compile-time 1–32-byte seven-bit seed through canonical
  `bump`, `check`, explicit-bump `checkBump`, and current-program-owned signed `createAccount`.
- `Svm.Sdk.System` exposes fixed-account `transfer` and `createAccount`; lamports and space remain
  ordinary scalar instruction values while account privileges and owner geometry stay static.
- Pda, Transfer, Create, and CreatePda consume these names. CPI tags, metas, signer seeds, and data
  words no longer appear in application code.

The extractor follows marked `pf_inline` facades into the existing SVM Runtime namespace instead
of recognizing each SDK name. Legacy single-seed `findPda`/`checkPda` IR now applies the same
bounded ASCII verifier as multi-seed groups. This adds no PDA/System Ops variant, IR node,
Component, or emitter recipe.

## Honest boundary

String fields projected through source descriptor records are not yet an extraction contract, so
this slice does not publish a plan object that only works in host Lean. Seeds are passed directly
and must be compiler-proven static. Runtime seed buffers, alternate program ids, dynamic account
tables, persistent pointers, the remaining System instruction families, and Token/Token-2022
facades remain closed or future R3 work.

## Evidence

- Focused SDK/example/spec builds pass, including canonical extracted-IR checks for all four
  consumers.
- Pda, Transfer, Create, and CreatePda produce 12 assembly/ELF/IDL artifacts byte-identical to the
  pre-facade baseline.
- The aggregate Lean gate passes 286 jobs; all 54 SVM programs build and all 162 top-level
  assembly/ELF/IDL artifacts are byte-identical to the pre-facade baseline. Because machine
  artifacts are unchanged, this slice does not repeat Mollusk or Surfpool deployment; Surfpool
  remains the only deployment qualification environment.
