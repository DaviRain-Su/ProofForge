# R1-003 — Bind shared scalars to SVM Borsh and EVM ABI

## Goal

Bind the allocation-free values from R1-002 to both target wire formats without moving Borsh/ABI
geometry into Core. SVM must use exact little-endian instruction bytes and fixed physical locals;
EVM must use canonical ABI words. Neither binding may introduce a heap object, persistent pointer,
or target storage layout into the shared value model.

This is the **scalar target-adapter slice**. Aggregate record/tuple/enum schema derivation remains
R1 work.

## Delivered

- `Svm.EntryAdapter` derives fixed Borsh leaf widths and logical-to-physical binder ranges from
  `Core.Codec.Scalar`. `UInt128` is two 8-byte little-endian leaves; `FixedBytes 12` is one 8-byte
  leaf plus one 4-byte leaf. Exact instruction and return lengths are checked, including short and
  trailing input rejection. A bare scalar use of a multi-limb source binder fails closed instead of
  silently choosing one limb.
- The SVM emitter loads native 1/2/4/8-byte leaves directly and assembles other final widths from
  checked bytes. Return data emits exactly the inferred typed width. The plan uses invocation-local
  scalar locals only; it does not allocate a `Vec`, `Map`, node copy, or account pointer.
- The EVM codec/emitter binds wide integers numerically to right-aligned ABI words and fixed bytes in
  source byte order to left-aligned `bytesN` words. Calldata rejects nonzero integer high bits and
  fixed-byte right padding. The bounded `pf_store_fixed_bytes` runtime helper owns canonical return
  packing, including bytes32 values passed to permit/ecrecover paths.
- Profile accepts a literal valid `FixedBytes n` index as compile-time metadata while continuing to
  reject direct `Nat`, polymorphic `FixedBytes n`, and invalid sizes at the entry boundary.
- `Examples.RawEntry` and `Examples.Wide` exercise the same shared `UInt128` and `FixedBytes 12`
  source values through target-owned Borsh and ABI adapters. The examples contain no target wire
  arithmetic or padding policy.

The ownership path is:

```text
Core.Value + Core.Codec scalar metadata
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
Svm.EntryAdapter        Evm.Codec
exact LE Borsh leaves   canonical 32-byte ABI word
        │                   │
fixed scalar locals     Yul stack/bounded memory
```

## Verification

- `lake build Tests` passes 237 jobs; `lake build` passes 98 jobs.
- All 51 SVM programs build. The locked Mollusk inventory is 286 tests; RawEntry contributes 12,
  including valid UInt128/FixedBytes12 roundtrips and malformed short/trailing inputs.
- RawEntry digest is `83dda49b07d85f48`; its ELF is 12,048 bytes. Surfpool 1.5.0 deployed the
  exact artifact through 12 Loader-v3 write transactions and verified the resulting ProgramData.
  `solana-test-validator` was not used.
- All 15 EVM programs build and Anvil passes 15/15. Wide digest is `692687089d4455f3`; its 1,152-byte
  deployment artifact covers valid and malformed uint128/bytes12 ABI words. Token digest is
  `4f1db71eb59d4254`; its existing name/symbol/domain/permit matrix passes with source-order fixed
  bytes.
- Ownership, whitespace, and registry digest guards pass.
