# l5-011 Phoenix-v1 bounded account-resident root slot

## objective

在不使用 Rust heap、Map 或摊平节点数组的条件下，安全读取运行时 root index 指向的
Phoenix-v1 bid node。读取直接作用于 market account bytes，不构造拥有节点的对象。

## bounded primitive

`accDataWordAt acc baseWord strideWords capacity index` 只允许 `index` 运行时变化：

- account、base、stride、capacity 必须在 Lean 抽出时是字面量
- 静态检查最大可达 word 不溢出 u64 data-length 计算
- 运行时先检查零基 `index < capacity`
- 再检查 `data_len ≥ 8 * (base + stride * index + 1)`，最后才形成 data pointer
- 任一边界失败以 `Custom(1)` fail closed

## Phoenix use

- Sokoban bid node 固定 64 B / 8 words
- 1-based root 只在 allocator header gate 后转成零基 slot
- profile 分支分别钉死 capacity 512/1024/2048/4096
- 读取 root links、parent/color 和 price；要求 parent=0、root black，直接 child 为 null
  或位于 `1..bump_index-1`

## verification

- Core target arity/static-shape guards 拒绝 stride/capacity 非法组合
- IR/assembly gate 钉住四档 indexed reads、index gate、stride multiply 和 data-length gate
- Mollusk 用 root index 2 从账户内第二个 slot 返回 price 999
- child 等于 bump、root parent/color 非零均返回 0
- digest `b2519600b8cfe99f`，assembly 878,132 B，ELF 282,536 B

## non-goals

- 不遍历完整 bid/ask/trader tree 或 free list，不判断 root 是否位于 free list
- 不验证 child-parent reciprocity、key ordering、red rule、black height 或 live-node count
- 不写节点/allocator，不开放 runtime base/stride/capacity 或 remaining accounts
- 不宣称完整 Phoenix-v1 账户/指令兼容
