# wsm-054 XrplMint 接 per-user `lock`

## objective

把 wsm-053 的 caller-card `lock` 接到 `Examples.XrplMint`。不是新 host。

digest `817c3e5c63e324ab`。

- `Error.frozen` → 状态码 5
- `freeze` / `unfreeze` 写 caller 卡 `lock`
- `pay`：caller lock 或 dest lock 非零 → 5，不扣款
- `takeFrom`：源卡 lock 或 spender lock 非零 → 5
- `burn` / `mint`：caller lock → 5
- `mintTo`：dest lock → 5
- 全局 `halt` 仍是 4，先于 `lock`

## 不做什么

- 不开 `Sdk.Map` / `Sdk.Payments`
- 不把 `lock` 放进 `State`
