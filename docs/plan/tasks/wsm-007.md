# wsm-007 XRPL-HASH：`compute_sha512_half` ASCII 字面量

## objective

本 Bedrock 镜像 `lejamon/rippled_smart_contract_vault_x86` 的 `rippled` 已注册
`host_lib.compute_sha512_half`（不是新 stdlib 的 `sha512_half`）。对标 SVM
`sha256Lit`：编译期 ASCII 字面量 → SHA-512Half 的**第一个小端 UInt64**。
完整 32B / 运行时缓冲 / keccak 全部 fail closed。

`Examples.XrplHash.stamp` 把 `xrplSha512HalfLit "vault"` 写入槽；本地节点从
`ContractJson` 读（本宿主不填 view `ReturnValue`）。

## 不做什么

- 不引入 `sha512_half` 别名、不复用 `sol_sha256` / `keccak256`
- 不返回完整 32 字节、不做动态输入
- 不做 SDK

- `#pf_xrpl_reject Examples.Hash`（svm `sha256Lit`）
- 本地：`stamp` 后 `hashed` 槽等于 SHA-512Half(`vault`) 的首个小端 u64
  （缺 docker 则 skip）
