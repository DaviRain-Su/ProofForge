# evm-005 Pair 多 slot：initBoth 写全字段 + Anvil

## objective

证明发射器不是 Counter 单槽模板。`initBoth left right` 按槽顺序写 `sstore(0)` 再 `sstore(1)`，最后一次才 `return`。`creditLeft` 只改 slot 0，slot 1 保持。

Anvil（有 Foundry 时 fail-closed）：

1. constructor(`uint64`) 写 left，right 保持 0
2. `initBoth(5, 99)` 写两槽
3. `creditLeft(3)` → left=8，right=99
4. left=max 时 overflow，两槽保持
5. `getLeft` / `getRight` 与 `cast storage` 双读

缺 anvil/cast：skip。
