# wsm-006 XRPL-CMP：三叶 AccountId 比较（Ownable 打底）

## objective

对标 EVM `eq20` 的**源码比较**，不新增 host。见
[xrpl-runtime.md](../analysis/xrpl-runtime.md) XRPL-CMP。

`init` 把 `xrplCaller20` 三叶写入 `owner0/1/2`。`bump` 仅当
`caller.w0/w1/w2` 全等 owner 才改 `value`；否则 `.error .unauthorized` →
wasm `i32` 状态码 **3**（1 overflow、2 divide-by-zero 已占用）。

不把 8 字节身份当权限目标。不引入 SDK / `pf_inline`。

## 不做什么

- 不新增 host import（没有 `eq_account`）
- 不做 hash / Map / SDK Ownable façade
- 不把 `Error.unauthorized` 映射成 EVM `Unauthorized(address)`

## path

`ProofForge/Wasm/{IR,Emit}.lean`（允许并发射 `errorNamed "unauthorized"`），
`Examples/XrplOwn.lean`，`ProofForge/Wasm/Xrpl/Registry.lean`，
`Tests/XrplSpec.lean`，`runtime-tests/xrpl/{check.sh,own.sh,fixture/abi.json}`

- `#pf_xrpl_build Examples.XrplOwn`；WAT 含三个 `i64.eq` 和 `(i32.const 3)`
- 本地：genesis `init` + `bump` 改 `value`；非 owner 的 `bump` 返回码 3 且槽不变
  （第二账户用 genesis Payment 注资；缺 docker 则 skip）
