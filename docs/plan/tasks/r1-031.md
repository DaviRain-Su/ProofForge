# R1-031 — Shared scaled UInt64 fixed-point policy

Date: 2026-09-01
Status: done

## Goal

Give SVM and EVM applications one reusable fixed-point multiply/divide vocabulary with explicit
floor/ceiling rounding, without copying the exact product/division implementation or introducing a
target operation.

## Delivered contract

- `Core.FixedPoint.UInt64` provides `mulDown`, `mulUp`, `divDown`, and `divUp` over an
  application-selected nonzero UInt64 scale. The division APIs distinguish invalid scale, zero
  divisor, and unrepresentable result through caller-owned typed errors.
- Every operation delegates to R1-029/030's exact 128-bit intermediate and single fixed 64-step
  restoring-division kernel. No fixed-point helper owns a second multiply/divide implementation.
- SVM `BatchSizer` and EVM `EvmPriceBand` independently bind the shared operations to their own
  state, scale/divisor errors, and overflow policy.

## Boundary

This is explicit-scale unsigned UInt64 policy, not a new physical fixed-point representation.
Typed fixed-point values and scale descriptors, conversions/casts, signed or wider fixed-point
arithmetic, and persisted fixed-point layouts remain fail closed. No target Runtime/Ops/IR/CFG/
Component/Emit case, allocation, pointer, or shared physical layout was added.
