# wsm-019 NEAR `current_account_id`（view-safe self，不是 Principal 9 叶）

## objective

wsm-018 开了五条 host 读。历史仓 ADR-0031 S3 的下一条是
`context.self` → `env.current_account_id`。本切片只开 **UInt64 前 8 字节 LE**，
和 `predecessor` 同一截断规矩；**不是** 9 叶 Principal。

```text
Sdk.Context.self
  → Runtime.currentAccountId   @[irreducible]
    → Extract.IR.ValKind.near .currentAccountId
      → env.current_account_id (register 3；不和 predecessor 的 register 0 抢)
```

View-safe（不像 predecessor）。SVM/EVM/XRPL 碰到这片叶子 fail closed。

## 不做什么

- 不做 Principal 9 叶 / `u32le(L)||utf8`
- 不做 Promise / NEP-141 / `signer_account_id`
- 不改 Counter digest `121a0c8f7e697642`
