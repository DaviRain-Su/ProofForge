# l5-002 Phoenix 限价 / TIF / 部分成交 / UInt64 费用

## objective

Phoenix level-0 IOC 吃单看 `askPrice` 和 time TIF。部分成交 =
`min(want, sizes[0])`。费用提供 UInt64 bps 计算，不是官方 u128。

本切片交付档 0 的限价、time TIF、部分/全部成交、Token `TransferChecked` CPI，以及
`sizes_0` / `baseFree` 双字段写回。宿主 `swapBuyAt` 还覆盖 slot TIF。跨档循环扫书、
红黑树和费用状态记账不在本切片内。

## path

`Projects/Phoenix.lean`, `Tests/PhoenixSpec.lean`, `Golden.lean`

## verification

- `limit < askPrice` overflow
- `unixTime ≥ expiry`（expiry≠0）overflow
- `want > sizes[0]` 仍成交 `sizes[0]`
- CPI 后保留 `sizes_0` / `baseFree` 两个 store
- UInt64 bps 可参数化计算
- `#pf_build Projects.Phoenix` 绿
