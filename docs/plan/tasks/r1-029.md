# R1-029 — Shared full-precision UInt64 multiply/divide

Date: 2026-08-31
Status: done

## Goal

Add allocation-free floor `(left * right) / denominator` for UInt64 callers without overflowing
the intermediate product, while preserving caller-owned typed errors and identical value semantics
across SVM and EVM.

## Delivered contract

- `Core.Math.UInt64.mulDiv` forms the exact 128-bit product from four safe 32-bit partial products,
  then performs one fixed 64-step restoring division. It returns floor division when the quotient
  fits UInt64, the caller's division-by-zero error for denominator zero, and a separate caller-owned
  overflow error when the quotient cannot fit.
- `denominator ≤ productHigh` is the complete quotient-overflow preflight. The division frame keeps
  only two UInt64 scalar locals and never allocates a wide heap value, pointer, table, or target
  scratch buffer.
- SVM `BatchSizer.prorate` persists a fractional capacity result with `zeroCapacity` and
  `ratioOverflow` policy. EVM `EvmPriceBand.weighted` independently persists a weighted quote with
  named `zeroTick()` and `quoteOverflow()` errors. State and ABI/account geometry remain
  target-owned.

## Boundary

This slice is unsigned UInt64 floor rounding only. Ceiling `mulDiv`, signed values, UInt128/
UInt256 roots and saturation, fixed-point types, and wider returned quotients remain fail closed.
No target Runtime/Ops/IR/CFG/Component/Emit case or shared physical layout was added.
