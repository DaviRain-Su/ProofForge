# l4-022 tokenAccountSize / sol_get_return_data

## objective

`tokenAccountSize` 是普通 Lean 包装，抽出成已有 `invoke`，返回值走新叶子 `cpiReturn`。

- 外层 0 dummy s+w（prelude）、1 mint r、2 Token
  内层 metas：mint r；data `u8le(21)`（1B packed GetAccountDataSize）
- 抽出后：`.invoke` 再 `.returnU64 .cpiReturn`
- `cpiReturn` 发射 `sol_get_return_data`，只取 8 字节小端 u64；长度不是 8 则 Custom(1)
- 完整 program id / 变长 return data 仍 fail closed
- 负例：缺 acc0 signer
