# l4-006 findPda 返回 bump

## objective

普通 Lean 名 `findPda seed` 抽出后发射 `sol_try_find_program_address`，返回 canonical bump（255..1）。

- 种子本切片钉死一条 ASCII 字面量；program id 用当前程序（entrypoint 后的 32B）。
- 返回 bump 一叶 `u64`（高位 0）。bump 0 / syscall 失败 → Custom(1)。
- 完整 32B PDA key 本切片不返回。
- `invokeSigned` / createAccount 本切片不做。
